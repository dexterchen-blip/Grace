# Grace V2.4 设计稿 —— 好奇心器官（Curiosity Organ）

> 立项：2026-09-09（用户定案："我觉得没毛病……可以命名成 Grace V2.4 了"）
> 前置：V2.3 注意力导向器（attention_director，已落地）+ 四层记忆 + self_activation 三源
> 理论锚：Loewenstein 信息缺口理论 · Panksepp SEEKING 系统 · 蔡格尼克效应 · Schmidhuber 压缩进步
> 社区背景：agent 架构普遍只做外在动机（任务跟随），内在动机（好奇心）普遍缺位——做出来即差异化

## 0. 定位一句话

好奇心器官 = **信息缺口追踪器 + 蔡格尼克激活 + 第四触发源 + 满足回路**。
它与注意力的关系：好奇心是注意力的**动机面**——注意力决定"看向哪"，好奇心决定"**想弄明白什么**"。

## 1. 为什么是"进一步研发"而不是新造（用户判断：难度不大——成立）

| 已有组件 | 在好奇心里的角色 | 缺的一步 |
|---|---|---|
| self_activation 三源之 SEEKING（事件价值） | Panksepp SEEKING=好奇心的神经基质，**评分器已存在** | 加第四信号源：缺口驱动 |
| L3 矩阵置信度（high/low/无）+ "记不清"路径 | **知识缺口的原始表征**（边界可计算） | 缺口事件没人收集 |
| claim_guard / verify（none/unknown 判定） | "记不清"事件的**日志已存在** | 从日志变账本 |
| 暗注意力 cog（背景念头） | 好奇心的**思维持续形态** | 缺口不喂 cog |
| proactive 通道 + W6 防话痨 | 好奇心的**行为出口** | 第四触发源未接 |
| attention_director 激活公式 | 好奇心与注意力的**连接器** | 缺口条目无激活加成 |

## 2. 四个部件

### 2.1 缺口检测（四信号，全部复用现成信号）

| 信号 | 来源 | 例子 |
|---|---|---|
| G1 检索低置信 | L3 fact_query 返回 low/无记录 | 主人提到"那个教授"，她没有该实体记忆 |
| G2 不确定事件 | claim_guard / verify = none·conflict | 她"记不清"主人的某个承诺 |
| G3 新实体 | mood_graph 首次出现的实体 | 图谱里第一次出现"MicroFridge" |
| G4 未接话题 | 主人消息含疑问但她未回应/回应未答 | 主人问过但她答非所问 |

### 2.2 缺口账本（核心创新：蔡格尼克激活）

`curiosity-ledger.jsonl`：{gap, salience, born_ts, attempts, resolved_ts}

**激活公式（与常规记忆相反）**：
```
gap_activation = base_salience × (1 + age_hours/24 × 0.3) × (1 - 0.4×attempts)
未解决 → 随时间上升（蔡格尼克：未完成的事记得更牢）
多次尝试未满足 → 抑制（防执念）
已解决 → 移出账本 → 触发满足事件
```
- 上限：账本 ≤12 条（Cowan 4±1 的 2 倍封顶），超额按激活值淘汰
- 每日主动提问预算 ≤1 次（W6 同款防过载——好奇心也要防"什么都要问"）

### 2.3 第四触发源（self_activation 扩展）

```
源④ EPISTEMIC：账本最高激活 × 亲密度门控（同现有三源框架）
触发 → 生成缺口驱动台词："上次你说的 XX，后来怎么样了？" / "雷姆对 XX 不太懂，主人能讲讲吗？"
```
- 台词生成走现有 proactive _speak 管线（monitor+守卫+回声防线全继承）
- **铁律兼容**：提问内容只能来自缺口账本（真实运行中产生的知识缺口），绝不人工造问题

### 2.4 满足与学习（内在动机的 RL 回路）

缺口填充途径：主人回答 / 她自己检索命中（L2/L3 新证据）/ 文档摄入覆盖
→ 满足事件：mood 日内事件（"好奇得到满足"的轻微兴奋，复用 apply_intraday_event）
→ 记忆强化：该条目在账本转正为已解决 + 进 L0（真实成长语料）

## 3. 与注意力导向器的集成（好奇心=注意力的动机面）

- 账本条目在 attention_director 中获得**好奇心加成**（act +0.2×gap_activation）→ 未解决的缺口持续占据 WM 焦点区候选
- cog 暗注意力喂料：账本 top1 缺口注入 cog prompt（"那个没弄明白的事…"）——好奇心的思维持续形态
- 说话方向/is_send、回声防线、身份冲突标注全继承，零新增风险面

## 4. 探针设计（V2.4 新指标）

| 探针 | 测什么 |
|---|---|
| 缺口持续率 | 账本条目跨天存活比例（蔡格尼克是否生效） |
| 提问质量 | 缺口驱动的问题 vs 随机问题的相关性评分 |
| 满足闭环率 | 缺口从入账到解决的转化率 + 满足事件触发率 |
| 好奇心过载率 | 每日提问数 vs 预算（应 ≤1） |

## 5. v1 范围（一轮做完）与非目标

**做**：G1-G4 检测（全部信号现成）→ 账本 → 第四触发源 → cog 喂料 → attention 加成 → 探针
**不做（v2+）**：自主探索工具（自己查资料——涉及工具权限面）、跨会话好奇心迁移、好奇心的情感分化（困惑 vs 惊奇）

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 不确定性校准不准 → 好奇心变噪音 | 保守阈值 + 每日预算 1 问 + W6 框架 |
| 缺口账本被噪声灌满 | 四信号白名单 + 账本 cap 12 |
| 提问打断主人（打扰感） | 复用 ToM 一票否决 + 时机窗口（现有 proactive 框架） |
| 成长语料铁律 | 缺口全部来自真实运行信号，账本本身是真实产物——不人工造缺口 |
