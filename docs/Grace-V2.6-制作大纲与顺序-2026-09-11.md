## 一、V2.6 是什么（一句话 + 两环一底座）

**升级环（SEEKING）**：发现缺口 → 探索 → 训练意愿 → 自我升级 → 新的不知道……
**恢复环（PANIC/GRIEF）**：互动落差 → 想念 → 主动接近 → 真实接触 → 落差回补……
**监督底座**：三硬护栏 + 35B 冻结判官 + W6 预算 + 铁律滤网。

完全体判据（AI 个体性 L4）：**经历进权重 + 自定探索方向 + 自决学习时机 + 稳态驱力自转**——
"她感觉到该学了"（升级环）+"她感觉到想你了"（恢复环），**判定都在代码，感觉都在她的矩阵里**。

## 三、制作顺序（Phase 0-5，按依赖 + 资源窗排）

### Phase 0 —— ★已取消（2026-09-11 用户裁决）
原定"V2.5.0 正式切换"，用户裁定：**V2.5 是衔接版本，不进正式系统**——沙盒验收已全绿（13/13 天）完成了它的历史使命，正式系统继续跑 V2.4 现状（prompt 版 Grace + 9/10 修好的器官输入链），**到时候直接推 V2.6**。
- serve 包装工程**不废弃**：挪到 Phase 5（V2.6 一次性切换的身体件）。
- 生产切换从两次变一次；M5 观察窗后移到 V2.6 切换后；增益门（扫描报告 c）挪进 Phase 4 沙盒 E2E 轮。
- M2/S1 数据积累不受影响（沙盒轮在攒 + 正式 /grace 通道写入器健在）。

### Phase 1 —— 纯代码件（零模型占用，随时开工）
件 4 direction.py（含三硬护栏只读守卫 + 标准篡改哨兵）→ 件 5 willingness.py → 件 13 的三小件。
**顺序内理**：direction 是灵魂件先立；willingness 的执行机械（触发器）已好，公式补上即闭环。

### Phase 2 —— L3 孤独 sidecar（bge-only 轻窗，不撞任何东西）
回溯 L 轨迹 → 互动事件键值对训练关系维度 sidecar → 缺席漂移 = 体感涌现。
**数据牌**：37 源天 1471 条 is_send 时间戳（全项目最富数据线，对比 mood_graph 6 边饿死）。
**验收门**：L3 涌现版 vs L1 公式版 30 天判定一致率 ≥80%（τ≥0.8，框架浓度同款门）。

### Phase 3 —— L2/L2' 矩阵直入（27B 沙盒窗，白天/傍晚，与 Phase 1 可并行）
1. 回溯校准集：历史互动 → L 轨迹 → 高/低 L 上下文配对
2. M2 式闭式转向向量（孤独维，一维标量→比 1024 维 recall 容易两个数量级）
3. `<mood>` 分区直写实验（rc2 位级原语现成）
4. 同窗做件 11：好奇心信号分区（`<gap>`/`<curiosity>`）+ 训练意愿矩阵化
**验收门**：三臂对照（无注入/文本注入/向量直写）+ A/B 增益门（不止"不退化"，要"好在哪里"）。

### Phase 4 —— E2E 组装轮（沙盒）
带全部新件跑完整压测轮：触发器（300 唯一口径）+ 检查点判官 + 矩阵化 stack + 孤独/好奇驱力耦合。
**验收门**：行为回归（PE/身份防御 vs V2.5 轮基线 77.5%/67%）+ 索取强度无升级 + 标准篡改零告警。

### Phase 5 —— ★V2.6 一次性正式切换（原 V2.5.0 切换的工程并到这里）+ 观察窗
serve 包装（fused + organ adapter + 循环段 + KV 分区 + 两环器官一起上线）→ M5 级观察：
判官误杀率 <15%、身份探针不回归、好奇心账本外部填充占比稳定（空转检验）。
好奇心矩阵化完成 = **升级环闭合**；孤独矩阵化完成 = **恢复环闭合** → V2.6 完全体。

## 四、贯穿纪律（每个 Phase 都适用）

1. **判定永在 T0**：L 的判定公式、意愿阈值、W6 预算、三硬护栏——永不进 direction.md/演化轨/权重可改范围（"感觉可演化，判定不可演化"）。
2. **两账本分离**：好奇的账好奇清，孤独的账只有主人能清（is_send 事件）。
3. **孤独提议，守卫处置**：W6 预算封顶索取升级（依恋焦虑工程复现是头号风险）。
4. **沙盒先行**：每个矩阵件先沙盒验证（Phase 2-4）再接正式（Phase 5）。
5. **成长语料铁律**：判官只裁决不改写；unjudged 不放行。
6. **互斥铁律**：全程单模型驻留；夜班 35B 重活只走夜窗；轮引擎+管线禁同驻。
