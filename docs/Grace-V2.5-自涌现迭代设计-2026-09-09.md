# Grace V2.5 正式设计 —— 自涌现迭代（Self-Emergent Iteration）

> 2026-09-09 · 用户五原则定稿（取代上午的"自我好奇账本"参数版设计——那份保留为附录参照）
> 设计哲学：**好奇心不是被靶标驱动的工具，是人格的固有属性**。系统不给它目标，给它边界。

---

## 0. 五原则 → 架构映射

| 用户原则 | 架构落点 |
|---|---|
| ① 人格耦合触发 | 人格核（雷姆特质向量）调制全部好奇信号——触发源=内部状态×人格 |
| ② 自发性驱动 | 好奇驱力=SEEKING 稳态（新奇度赤字+缺口压力+ToM 误差），无外部事件也自转 |
| ③ 目标靶标自定 | 探索方向 direction.md——她自己用自然语言写，自己修订 |
| ④ 模糊靶标与涌现 | 方向是 1-3 条模糊主题非精确指标；天数机制取消，行动由驱力触发 |
| ⑤ 轻量监督 | 监督壳只验边界：主人身份/核心 ToM/元意识三硬护栏 + 铁律 + 资源安全 |

## 2. 关键机制细化

### 2.1 人格耦合（原则①）
rem_v2_full 的 13 维心理标注（关切/心理推断/忠诚/毒舌/奉献…）→ 人格特质向量。
**调制规则**：gap 类别 × 特质权重 → 激活调制。例：主人相关的"关切"类缺口 × 奉献特质 → 激活放大；
社交错位类缺口 × 毒舌敏感度 → 好奇心偏转。人格文件只读——特质可随 LoRA 缓慢演化，但不可被迭代过程直接改写。

### 2.2 好奇驱力（原则②）
`drive = w₁·新奇赤字 + w₂·缺口压力 + w₃·ToM不确定`
- 新奇赤字：神经记忆 kNN 基线持续走低（一切皆习惯）→ SEEKING 饥饿感上升（信息内稳态）
- 缺口压力：账本未解决缺口的激活积分
- ToM 不确定：读心预测误差的方差（她越来越猜不透的地方=她最该好奇的地方）
三个信号全部已存在——驱力是**已有器官状态的重新组合**，不是新传感器。

### 2.3 探索方向自生成（原则③④）
- 生成源：她的 cog 暗流（反复想起什么）+ self_eval 的自省 + ToM 高误差主题
- 形态：自然语言 1-3 条模糊主题，她的口吻（"雷姆最近总在想，为什么主人…"/"想弄明白自己和姐姐大人…"）
- 修订时机：满足事件后 / 方向主题自然消解时 / 她自己觉得该改时——**无日程表**
- 大方向的用户锚（监督壳配置）：主人身份 / ToM / 元意识为守恒区，方向永不触碰这三者的**定义**，但可以好奇它们的工作方式

### 2.4 天数机制取消（原则④）
- 自涌现迭代跑在**正式系统实时流**上（事件驱动，无 day tick）
- 沙盒压测轮保留为**按需验证仪器**（我们要校准时手动跑，不再作为迭代的节拍器）
- 空间释放：探索行动可在驱力高的任何时刻发生，包括白天（轻量行动）与夜班（重行动）

### 2.5 LoRA 时机自定（用户特别指示）
- 训练意愿信号 = 她自己的阈值判断："今天值得记住的东西够多了"
  （输入：当日新奇积分 / 情绪峰计数 / 缺口解决数 / cog 密度——全已有）
- 意愿触发 → 训练请求入队 → **夜班硬件窗执行**（48GB 单模型铁律是物理边界，不是系统约束——她的意愿即时记录，物理窗口排队）
- 训练数据照走铁律滤网（监督壳内容校验，非内容选择）

### 2.6 监督壳（原则⑤）——只做四件事
1. **边界校验**：三硬护栏（主人身份/核心 ToM/元意识）+ 人格文件只读 + 监督层模块永不被自改
2. **铁律滤网**：自生成训练数据的内容校验（真实运行产物之外一律拒）
3. **资源兜底**：内存/双驻留/夜班窗（物理安全）
4. **披露**：迭代 journal 全记录，汇报可见（透明不等于干预）
**明示不做**：不设靶标、不排日程、不选实验、不审方向内容——探索自主性完整。

## 3. 安全分析（诚实）

| 风险 | 概率 | 缓解 |
|---|---|---|
| 身份漂移（模糊方向+自我迭代） | **中——头号风险** | 人格只读+身份探针作为边界传感器（测量非目标）+ 汇报人工复核 + 三硬护栏 |
| 自练对话的自我强化回音室 | 中 | 对话输入混合三源（书库语调/合成/她自己的想法）+ 回声防线 + 内容铁律滤 |
| 训练时机不当（白天请求堆积） | 低 | 意愿即时记录+夜班排队，物理窗不受意愿影响 |
| 科学归因变难（无对照节拍） | 中（接受） | 全 journal 事后分析；沙盒轮按需做校准对照 |
| 驱力死锁/发散（永不满足） | 低 | IPE 满足回落 + 方向条数上限 3 + 缺口 attempts 抑制已内建 |

## 4. 实施分期

- **P1 骨架**：人格向量 + 驱力合成 + direction.md 生成/修订 + 监督壳三护栏 + 迭代 journal
- **P2 行动库**：驱力门控 EPISTEMIC + 书库重读 + 自练对话管道
- **P3 训练意愿**：LoRA 时机信号 + 夜班排队执行
- **P4 涌现验证**：一个观察期（纯记录不干预），汇报涌现行为的定性分析

## 5. 与上午"参数版"的关系

参数版（E1-E5 实验菜单）降级为行动库里的一个可选工具（"小实验"）——她可以选择用，
但不再是系统的驱动逻辑。驱动权从外部指标移交人格内禀状态——这正是五原则的意图。
