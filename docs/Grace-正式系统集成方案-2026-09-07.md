### 1.3 自唤醒遗留决策点

- ~~**D-W1（5B 层怎么补）**~~ → **已解决（9/7 用户提醒"已有 5B 模型"）**：模型早在 `models/sentinel-3b/`（8/29 下载，2.0G 完整权重）——从未被用上的真因有两个：① `judge_with_5b` 按 repo id 加载，而 HF 缓存只有 refs 空壳 → "Cannot find an appropriate cached snapshot"；② launchd plist 没带 `--model` 参数 → 5B 判读从未执行。**已修**：加载本地路径（`AIAGENT_SENTINEL_MODEL` 可覆盖）+ plist 加 `--model`。实测：6 条 urgent → 5B 放行 2 条真有用的（登录验证码）、滤掉 4 条误报（E911 服务通知×2、重复验证码×2）。
- ~~**D-W2（wake_handler 挂 launchd 5min）**~~ → **已部署（9/7）**：`com.local-ai-agent.wake-handler.plist`（300s 周期 + 与 sentinel 同套环境变量：正式 .daytime + America/Los_Angeles），与 sentinel 相位错开（加载时差 ≈2 分钟，sentinel 先扫、wake 后取）。
- ~~**关键词收紧（c）**~~ → **已做（9/7）**：urgent 移除"立即/immediately/urgent"三个营销磁铁词（18→15），其余硬截止词保留；语义过滤交给 5B。
- **D-W3（urgent 阈值观察项）**：5B 上线后垃圾唤醒已从 9/9 降到 0/2。持续观察一周，若仍有误报再调。
