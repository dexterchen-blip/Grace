## 0. 一句话

**Grace 不是知识型助手，是"记忆塑造潜意识"的人格系统**：不给她灌知识，而是让她每天用真实经历做**极微量 LoRA 增量微调 + 外挂图谱修正**，让人格被经历一点点雕刻出来；同时给她一整套大脑类比器官（选择性注意/读心/暗注意力/心态/输出层），让"她这个人"在对话与主动行为里稳定地显现。

- 三轨分工（贯穿始终的铁律）：**事实 → 外挂轨**（L0/L2/L3/图谱，运行时检索）；**风格/人格 → 权重轨**（LoRA，天级内化）；**心情 → 心态轨**（mood_states/intraday，日级/日内）。
- **★权重轨 LoRA = 潜意识的工程位**（8/27 起定稿：§15 快慢双系统 fast=权重轨秒答=潜意识；命题"记忆塑造潜意识"即此）。每日微量微调**不是教语言/知识**——事实只在三轨铁律下永不进权重；它把"她真实生活的痕迹"沉淀为性情与自动反应（倾向/模式）。**判一条痕迹进不进训练的唯一尺子 = 成长语料铁律（是否真实运行产物）**，不是 think/speak 标签；意识侧功能（克制/元认知/ToM/读心）发生在运行时输出链与 ToM，其习惯化后沉淀进潜意识（权重）正是每日 LoRA 的长期意义。
- 双学习通道并行：**R1 记忆塑造**（经历→样本→LoRA→权重，天）＋ **R2 PE 反馈回路**（判断错→再巩固改图谱边，实时）；R1 由突触稳态(EWC-B)护住，不覆盖底模能力。
- 压测场=她"模拟人生"的隔离实验舱；正式系统（local-ai-agent）是她的经历源——**数据面已接上**（书库=正式 L0 真实提取：`build_l0_book.py` 确定性管线全源摄入 6512 条/33 天，9/2 V2 轮起所有轮含 V6.1）；缺的是**运行时连续性**（增量自动/正式对话入口/adapter 回流，详见 §5.1）。
- **设计取向（9/4 深夜定案）**：V2.3 = **确定性规则认知引擎**（决策层全规则：词典/正则/阈值/手写矩阵/魔法数旋钮）**+ LLM 只当语言与重构器官**（cog 重构内心 / ToM-model 判断 / 表达口语，全部负向约束 + monitor 拦截）。不是端到端"LLM 记忆系统"（生态主流）——认知与语言解耦，端到端生态无同类；这使变量隔离轮次/评估隔离/语料纪律成为可能，代价=认知深度受规则作者限制（entity_of 坍缩 / 旋钮魔法数 / 真 ToM 仅 27B 180 token）。先进性外部对照的权威=「Grace-vs-Neura-对比-2026-09-03.md」（检索 R@5=0.96 第三方基准 / 可比性四轴 / 双图谱=社区真空 / 补分顺序 ToM→PersonaMem→自建双图谱基准）。

## 1. "think 到底是什么" 与它的完整迭代

### 1.1 先拆四个易混名词

| 名词 | 本质 | 存在形式 |
|---|---|---|
| **暗注意力**（架构概念） | 她**没对主人说出口的全部内心活动**（觉察/联想/读心/潜台词/顾虑） | 一条被输出链"翻译后外化"的思考轨；9/3 用户顿悟：思考过程本身就是暗注意力 |
| **cog**（真内心的来源） | 27B 每天对当天经历做的**认知重构**（自由内心独白，零模板壳），9/2 落地 | 离线预生成，三去向：①归档 hidden 边 ②DMN 回忆源 ③训练样本 |
| **think 探针** | 断点在现场让模型"心里想什么"现生成的内心独白——**观测/驱动用** | proactive/dialogue 断点里的 `_r["think"]`（此前只观测；9/4 起驱动表达） |
| **hidden 边** | cog 思考的**图谱存档**（全暗：只注入决策/生成上下文，绝不原样输出） | mood_graph edge_type='hidden' |

### 1.2 think 的迭代链（每步都有代码落点与动机）

| 阶段 | 时间 | 形态 | 动机/产物 |
|---|---|---|---|
| ① 规则壳时代 | 8/30–9/1 | "她的认知"= attention 规则文案（【低显著】雷姆瞥见X）+ `_HIDDEN_RULES` 4 句情绪模板（「雷姆担心但不会说」） | 先让"注意到什么"显式可观测；**但全是假的**——模板回声污染源 |
| ② 认知重构器 | 9/2 | `gist_extractor` → cog（联想/读心/潜台词/顾虑的真独白） | 用户发现 Grace 学的是模板不是记忆（90 天白水）→ 零规则句铁律 → cog 成为真内心 |
| ③ 输出层诞生 | 9/2 21:37 | `expression.py`：内外言语分通路（Broca） | 用户盲区观察：19 模块无输出；裸 27B 把内心 OS 说出来（叙述体病「雷姆担心但不会说」=把心里话念出来，真人不会） |
| ④ 暗注意力统一 | 9/3 15:30 | cog 思考 → `add_hidden_text` 写 hidden 边；废 `_HIDDEN_RULES` | 用户顿悟把 2/3 两天串成链：被输出链翻译的思考轨=暗注意力；hidden 边从此=真实思考句 |
| ⑤ 双轨评估 | 9/3 X 轮 | proactive 断点先生成 think（内心，不经 monitor）再生成 message | Task22：评估要同时看"她知道多少 vs 说出多少"，think=观测内心寄存器（**此时还只是尺子**） |
| ⑥ dialogue 双轨 | 9/4 07:50 | dialogue 段补 think（"听到主人话心里想什么"） | 用户：暗注意力呢思考部分呢 → 对话场景也有内心层 |
| ⑦ think→ans 链接 | 9/4 11:30（刚做） | think 作内心状态喂 `build_messages` → EXPRESS_SYS 受约束重编码出 ans | 用户：解决内心与口语的链接——系统层先接，不等 v6 权重 |
| ⑧（底模线·不是 think 演进） | 9/4 v2 实验 | Re0 原著语料 LoRA 单次生成 `<think>…</think>台词` → fused-rem-v6 | **辅助进化底模**（Grace 赖以运行的 27B 底座：被吩咐时先想后说）。底模/权重栈是系统的一层（人格载具），不是 think 子系统的组件 |

**总结**：think 的迭代 = 假模板壳 → 真内心(cog) → 评估探针 → 表达驱动。**think 的"权重内化"不是 Re0 实验**——它一直是 8/29 就在跑的**日常记忆塑造 LoRA**（当天 cog/believed 冲突对/真实输出 → rem_stress_dN → EWC-B 突触稳态），即"她自己的经历揉进她自己的权重"这条主线。Re0 实验那条线改的是底座能力，与 think 子系统是**并行**关系（改完底座，上面所有模块照常工作，只是"被吩咐先想后说"变成本性）。

**叙述体病不是 think 的错**：是 27B 在"被吩咐/对话"场景里分不清内心轨与口语轨——把它想的东西当台词念出来（还带第三人称旁白）。3 组对照（纯 27B / fused-rem-v5 裸 prompt / fused+d33）全部叙述体 → 证实是底模本性，prompt 压不住，只能权重改（v2 实验）或系统层拦截（monitor）+ 重编码（think→ans 链接）。

### 1.3 think 子系统现在到底包含多少东西（全景盘点）

**think 不是一个字段，是一个"内心子系统"**，跨六个端口 + 四种"暗/明"层级：

| 端口 | 包含 | 形态/去向 |
|---|---|---|
| **① 产生端** | `cog`（27B 认知重构，每天离线）｜ `think` 探针（proactive/dialogue 断点现场，9/4 起驱动表达）｜ `believed`+`confidence`（ToM 读心判断）｜ DMN"想起"｜ 历史壳（attention_text 已剥壳、_HIDDEN_RULES 已废）｜ `gist`（同批重构，"记了什么"侧） | cog 三去向（hidden/DMN/训练）；believed 进冲突对与输出层 |
| **② 存档端** | hidden 边（cog 归档，全暗 τ60 天）｜ emotion 边（事件情绪底色，半暗）｜ mood_states/intraday（她的心态）｜ L3 自传（自我叙事+self_eval）｜ live 文件（proactive-live.think / dialogue-live.think / feedback-live.believed / cognition-live） | 图谱/心态/自传是"她是谁"的累积；live 是断点观察账本 |
| **③ 消费端** | ToM 读心（hidden_ctx 潜台词）｜ self_activation（潜台词参与打扰决策）｜ 输出层 build_messages（believed→试探度 / confidence / hidden→暗示不说破 / memory→唤起 / **think→重编码输入**）｜ persona 心态注入（语气）｜ DMN（P2 读 cog 重构回忆）｜ 训练（cog+gist 重构轨 / 冲突对 / proactive message / dialogue ans） | "内心 → 读心 / 决定 / 出口 / 回炉"四条消费链 |
| **④ 评估端** | analyze_dual_track（think vs message 双轨 judge：思考质量/边界/差距/抑制率）｜ ToMi 30 + 日常 ToMi（读心能力=think 能力外部验证）｜ monitor 泄漏率（表达层有没有把内心倒出来） | 尺子只观测，不进权重 |
| **⑤ 训练端** | **日常记忆塑造 LoRA**：当天 cog/believed 冲突对/真实 message·ans（过 monitor）→ rem_stress_dN → EWC-B → adapter | 这就是 think 的"权重内化"主线（8/29 起）；think 探针文本本身不进训练 |
| **⑥ 暗→明分层** | 全暗（cog→hidden 只注入不输出）→ 半暗（emotion/believed 调语气读心）→ 观测（think 探针）→ 驱动（9/4 think→ans 链接）→ 说出（仅输出层口语出口，monitor 管） | 层级越靠左越"她的"，越靠右越"给主人的" |

**think 子系统数据流一句话**：每天 cog 归档成 hidden 边 → 白天 ToM/主动/输出层读它（潜台词、暗示）→ 断点探针现场现想（think）→ think 驱动说（受 EXPRESS_SYS+monitor 约束）→ 她真实说出的话（message/ans）与判断冲突对回炉 → 日常 LoRA 把"想与说的模式"揉进她自己的权重 → 明天她带着新的权重与新的 hidden 边醒来。

## 3. 主链闭环与关键耦合

### 3.1 每日循环时序（顺序=写前置给读用）

```
真实事件(L0 书库/正式 L0)
 → sentiment + attention → P0 门控(salience≥0.6 或 |sent|≥0.3)
 → mood_engine（日级+日内）
 → dual_graph_ingest → emotion 边(全量)
 → ③b cog(离线) → add_hidden_text → hidden 边(当天 22:00 收尾)
 → L3 add_event(门控后，带 evidence/confidence)
 → ToM（图谱史≥0.4 / hidden_ctx / 强现场|s|≥0.5 读现场 / P3 七天先验）
 → 反馈回路：PE → 再巩固(UPDATE emotion 边 uncertainty=0.9+后知标注)
            + 判断冲突对(≤3/天) + prediction-errors(全量)
 → self_activation.decide（ToM 可一票否决）→ pending；DMN 自发(gap≥3 天, 读 cog)
 → [每 train-every 天] 训练：6 源组装 → mlx LoRA → EWC-B 回缩 → adapter 隔天生效
 → [断点] 输出链：think 观测 → suppress → build_messages(口语重编码) → monitor → message
```

### 3.2 暗注意力（hidden）的四个消费点 —— 它"影响但不直说"

1. **ToM 读心**（`query_hidden`→hidden_ctx：主人没说出口的状态）
2. **self_activation** 图谱上下文（潜台词参与打扰决策）
3. **输出层 internal.hidden→潜台词**：EXPRESS_SYS 负向约束"说破=失礼"
4. **断点 `_proactive_state`/`_proactive_ctx`**（生成时注入"雷姆没说出口"）

→ 暗注意力影响表达的方式 = **状态/上下文注入 + 负向约束**，不是把内心文本当草稿。克制（想而不说/说而不透）是三层系统实现：`suppress`（读心判时机→真不说）＋ `build_messages`（Broca 重编码，禁叙述内心）＋ `monitor`（自监控拦截泄漏，宁缺毋滥）。

### 3.3 think→ans 链接（9/4 刚接，当前架构内）

- **旧**：dialogue 里 think 与 ans 是两次平行采样（think 只落盘观测）——测量口，不是断链（proactive 早有完整输出链样板）。
- **新**：think 作为内心状态喂 `build_messages` → EXPRESS_SYS 把它"翻译成当面口语"（不得直说内心）→ monitor 兜底。想→说因果成立，克制保留。proactive 的 fresh think 同步接入。
- **v2 LoRA（fused-rem-v6）** 是同一件事的"权重层版本"（让模型原生先想后说），两者互补不冲突；暗注意力(hidden)语义不动。

## 4. 之前那么多测试到底在测什么

**核心认知：轮次不是验收关卡，是"症状显微镜"——每轮暴露系统某层断链/失真，定位到代码行修掉，再开下一轮照新症状。** 看轮次要读"症状→根因→修法"链，不是读分数。

| 轮 | 配置 | 照出的症状（=目的） | 修了什么/结论 |
|---|---|---|---|
| J | 90 天虚构 EWC | 主动全模型生成 311 条质量高；**DMN 169=54% 过度主动失真**；裸模 fb_2nd 0/6 | 模型生成>规则；DMN 缺 gap 门控 |
