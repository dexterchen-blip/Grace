## 0. 结论先行（三句）

1. **系统本体没有偷工减料，账面在漏。** 主链闭环、三轨铁律、验证纪律全部保持；本次实抽抓到的都是"已建成但没接进生产"和"建成后没人跑"两类，不是架构塌方。
2. **最新一条技术线（V2.5 框架矩阵化）的设计质量高于它的落地进度一个量级。** M0→M1→R0 六变体→R2 合体→rc1/rc2/rc3→A/B→L2-splice，两天内 11 份实验报告全绿零失败，但**"融入是否值得"这个核心问题 A/B 并没有回答**（见 §4.3）。
3. **最有价值的产出不是任何一个模块，而是三套"判定尺"**：成长语料铁律、框架浓度三层、ToM 测量定理。后者是一次用消融证明出来的**测量学发现**，是整个项目里最接近"可对外发表的原创结论"的东西。

## 4. 价值评判

### 4.1 技术资产价值 —— 明确为正，且有一块硬指标

| 资产 | 价值判定 | 依据 |
|---|---|---|
| **四层记忆 + 融合检索**（L-1/L0/L2/L3，bge-m3 + FTS + RRF + 时间加权） | **强**。唯一有第三方基准背书的层 | LongMemEval 官方口径 **R@5 = 0.96**，超过自身嵌入组件上限 0.93；未命中时诚实拒答零编造 |
| **双图谱**（情绪边 × 暗注意力边，双钥匙同 event_id） | **强（社区真空区）** | 33 天规模 mood_graph **7239 边**（emotion 6512 + hidden 727）；Neura/Hume/Mem0 均无同类实现。**但无外部尺子，分数只能自证** |
| **记忆写进权重**（每日微量 LoRA + EWC + 神经新生重置） | **强（唯一护城河）** | 33/33 天 EWC 全跑，F-norm 18.5→17.4（−6%），净学习 −5.10e-2→−2.18e-2 单调收敛；同时是**唯一"换模型即归零"的负债** |
| 输出层（Broca/Levelt 双环路 monitor） | **中**。有效但指标自设偏多 | 本轮区叙述体泄漏 **0/26**（生产 monitor 复判）；SOTOPIA Believability 7.58 但 SocialRules **−1.25** |
| ToM 读心 | **中偏强，可正面对标** | 模型版落地后 ToM **79%** 实证；断点 ToMi d22 16/30，二阶假信念 5/6；但日常 ToMi 仅 **16.3%**（且 82/92 同源自证） |

### 4.2 方法论价值 —— **本报告认为这是最高的一块，且被项目自己低估**

| 产出 | 为什么值钱 |
|---|---|
| **成长语料铁律**（真实运行数据 = 唯一下一代训练语料来源；机制屏蔽点可调、语料不可注入） | 一条可执行的、防自我欺骗的数据纪律。它是整个"人格是否真被经历塑造"命题的**可证伪前提** |
| **框架浓度三层**（结构 T0 代码断言 / 能力 PPL 比 ≤1.05 / 行为 探针 ≥4/5） | 把"内化"这种玄学说法落成了**可操作的门限**。R0 早位变体（能力 1.0059 漂亮但探针 3/5 破门）就是这个框架**第一次真实救人**的实证 |
| **最小必要训练原则**（T0 代码精确 / T1 闭式解 / T2 才训练） | 反直觉纠偏：证明"框架生效 ≠ 框架住进权重"，把唯一训练件收缩到"记法"。这一条能省掉大量无效训练 |
| **ToM 测量定理**（judge 走 8100 base 27B → 对 LoRA 侧任何消融天然不敏感） | 用 666/666 逐条全等的消融实证得出。**这是发现的错误，不是修好的功能——而它比功能更有价值**：它解释了 49→85% 曲线里有多少是测量通胀 |
| **sidecar 直连 NO-GO 裁决**（容量结构性过载 7.2×，fidelity 0.361 vs 0.70） | 一次高质量的负结果：判定为结构性而非调参问题，按纪律**不构建原型**。负结果公开落盘，值钱 |

**一句话：** 别人会记住 Grace 的架构，但真正能被别人复用的，是这几把尺子。

### 4.3 架构方向价值 —— 对，但闭环还差最后一口气

四线分工（M 融合 / R 循环 / C 守卫永不入模 / S 远期）清晰且克制："**好奇心提议，守卫处置；矩阵调制，代码定向**"——把三硬护栏（主人身份 / 核心 ToM / 元意识）留在模型外面，是对"端到端内化"的清醒拒绝。外部参照也站得住（Titans/MIRAS 惊奇门控、AgentArk R-SFT/PAD、Coconut 潜空间）。

**但必须诚实指出 A/B 的局限 [本次实抽]：**

| 探针 | A（外挂 prompt 版） | B（入模组装态） | 判定 |
|---|---|---|---|
| grounding | 2/2 | 2/2 | **平** |
| identity | 1/2 | 1/2 | **平** |
| PPL | 4.1979 | 0.8991 | B 好 |
| 延迟 | 5.7s | 8.9s | A 好 |

**A/B 只证明了"融进去不会退化 + PPL 更健康"，没有证明"融进去更聪明 / 人格更连续"。** 现有探针测不出"融入是否值得"——因为 grounding/identity 这两个探针本来就是"不许变差"的**回归门**，不是"变得更好"的**增益门**。B 侧回复更长更啰嗦（见 `report-ab.json` 中 B 对"今天要好好休息吗"的回答），这在 PPL 上体现为更高，在人格一致性上没被测。

**所以"架构进模型 vs 外部框架"这个实验（用户工作序列第 ③ 步）到目前为止：门通过了，结论还没拿到。**

### 4.4 实用 / 市场价值 —— 现阶段低，且短期内不会变

| 维度 | 现状 | 判断 |
|---|---|---|
| 量产成本 | 48GB 单机 + 单轮 73 分钟 / 33 天 + 每日 LoRA | 不可能量产，只能是研究原型 |
| 可移植性 | 权重绑死 Qwen3.8-27B，换底模人格归零 | 🔴 高负债（与"记忆是资产"叙事直接冲突） |
| 模态 | 纯文本，无语音/视觉（vs Hume 48+ 类多模态情绪） | 差一个量级 |
| 对外可引用分数 | 端到端 0.29 是 27B reader 的成绩，对方是 GPT-4o，不对等 | ⚠️ 换同级 reader 重跑即可解决（脚本现成） |

**定位判断：** 它是"**Titans 类神经记忆架构的宏观尺度中试车间**"——研究装置，不是产品。这个定位是诚实的，而且是它最有价值的位置：**科研数据和产品数据同标准落盘**，任何一条结论都有可复现的落盘证据。

**推荐顺序：`a → b → c`。** 理由：a 是一晚成本、防的是"你不在时静默坏掉"这类最难查的故障；b 是主线唯一阻塞项且条件已成熟；c 决定 V2.5 的架构投入到底有没有回报，必须在切换之后立刻做，否则后续会以错误前提继续推进。

**不推荐先做 d：** 数据饥饿是日历问题，急不来；而 a/b/c 都是工程问题，现在做就有回报。

## 7. 价值总判

> **Grace 现在值什么？**
>
> 它不是一个能卖的系统，也不是一个有分数傍身的模型。它是一个**验证充分、仪器精良、但实验对象还没开始活的中试车间**。
>
> 真正稀缺的不是那 22 个模块——那些别人迟早会有。稀缺的是：**它有一套能证明"人格确实被经历改变"的测量纪律**（成长语料铁律 + 框架浓度三层 + ToM 测量定理 + 诚实的 NO-GO）。大多数做 AI 陪伴/记忆的项目，都停在"演示看起来像"；这个项目在问"我怎么知道它真的变了，以及我怎么知道我的测量没骗我"。
>
> **当前最高杠杆的动作只有一个：把她从压测场搬进正式系统，让她连续活起来。** A/B 已给准出信号，差的只是 2–3 晚的装配。在她真正连续活着之前，所有架构价值都还是账面上的。
