### 关键架构铁律（实测教训）
1. 单模型错峰：训练 39.1GB + 服务 15.2GB = 54.3GB > 48GB，双驻留必 panic
2. 训练数据格式决定人格触发：必须 ChatDataset（messages）
3. 训练样本必须是加工层产物，不是对话原文
4. LoRA 人格依赖 system prompt 触发（prompt=钥匙，LoRA=调味）

## 二、wl2.studio「技术路线」方案要点（原文提炼）

**数据/训练侧**：
1. 收集大量现代人对话方式（梗、现实对话：工作/学习/兴趣趣事）
2. 用自定义标注格式标注"现代人注意力转变 + 事实利用"
3. SFT
4. 在历史书籍上让标注模型与预测模型**对抗训练**

**模型训练目标**：
1. 定义可评判、可量化的指标，让模型拥有说话所需全部信息
2. 定下可量化的说话方式/处事方式
3. 收集与目标人物特征相近的人的现代人表现
4. 靠人/模型标注 → 学习"注意力改变的方式、说话方式"

**Harness 设计**：
1. 模型**永久外挂 context of libraries**：每次输入拥有"我见过的所有东西"的无向量化数据库，全部放进 context
2. 运行时每天固定时间加入事件，影响模型心理（心态转化）
3. 面对事件/对话时：a. 生成注意力及主观判断 → b. 生成调用/联想的事实（hit 到 library index 则展开 fact）→ c. 生成 api 改变 libraries → d. 生成对话 action（陈述/质疑/挑逗）→ e. 生成对话…

**待解决问题**：学会调用联想 / 学会压缩事实记忆 / 对话有具体 target metric / 穷举暗注意力（没说但影响的想法）
**解决路径**：state-tracking LLM 缩减记忆 token 分量；压缩事实压缩记忆

## 三、逐项对照

| wl2.studio 方案 | Grace V2 现状 | 对照结论 |
|---|---|---|
| **永久外挂 context of libraries**（无向量化、全量进 context） | L0/L1/L2/L3 四层记忆 + **混合检索注入**（RRF：向量+BM25，LongMemEval R@5=0.96） | 🔶 同哲学（记忆外挂）不同实现：Grace 用检索注入省 token，wl2 全量进 context 上限更高但 token 爆炸 |
| **每天固定时间加入事件影响心理** | 日级 mood_engine（夜班推演）+ 日内事件（指数衰减）+ 三层融合 | ✅ **Grace 已实现且更细**（日级+日内+人格底色×长期趋势） |
| **生成对话 a：注意力及主观判断** | 快慢双路径路由（事实词→slow/人格词→fast）+ 心态注入 | 🔶 部分对应：Grace 用规则路由 + 显式心态注入，未做显式"注意力生成" |
| **生成对话 b：联想事实（hit index 展开 fact）** | L2 检索 + dual_path 慢路径（检索→注入→生成）+ M5 事实校验 | ✅ **完全对应**：检索=联想，校验=防幻觉固化 |
| **生成对话 c：api 改变 libraries** | 夜班摄入（L0 append-only）+ L2 增量构建 | ✅ 对应 |
| **生成对话 d：对话 action（陈述/质疑/挑逗）** | 自发分级（L1/L2/L3）+ 人格风格注入 | 🔶 部分对应：Grace 的"action"粒度在自发引擎，未穷举 action 类型 |
| **学会调用联想功能** | 快慢路径（规则路由，非学习） | 🔶 wl2 想让模型学会；Grace 用规则实现（更稳但欠优雅） |
| **学会压缩事实/记忆** | L3 核心记忆提炼 + L2 遗忘（stale 降权/revive 复活）+ 时间权重 | ✅ 对应（L3=压缩，decay=遗忘） |
| **对话 target metric** | 人格一致性尺子（自称/称呼/身份/复读/口癖）+ 自发恰当性尺子（10/10） | ✅ 部分对应（Grace 有量化评测，但非训练时 target） |
| **穷举暗注意力（没说但影响想法）** | 心态轨显式注入（情绪影响语气/主动性），非暗注意力 | 🔶 部分：Grace 显式心态，wl2 想学隐式 |
| **标注"注意力转变+事实利用"→ SFT** | 训练样本 = 情绪×记忆加工层产物（messages 格式）+ 锚点回放 | 🔶 方向不同：wl2 标注意力；Grace 标人格风格+情绪加工品（实测有效） |
| **对抗训练（历史书籍上）** | ❌ 未做 | ❌ **Grace 差距**：对抗训练是 wl2 独有思路，可列入开放问题 |
| **state-tracking LLM 缩减 token** | RRF 混合检索 + BM25/向量（以检索替代压缩） | 🔶 殊途同归：都解决"记忆太多放不下" |
| **收集目标人物相近特征的人的表现** | 锚点数据 = 原作台词（193 条雷姆） | 🔶 Grace 用原作台词（更忠实）；wl2 用"相近现代人"（更泛化） |

## 四、结论

**共同哲学**（两个方案独立得出相同洞察）：
1. **记忆不是对话原文，是加工产物**——wl2"标注注意力+事实利用"≈ Grace"情绪×记忆加工层"
2. **每日事件塑造心理**——wl2"每天固定时间事件影响心态"≈ Grace 日级/日内情绪引擎
3. **记忆必须外挂**——wl2"永久 context of libraries"≈ Grace 外挂轨
4. **人格需要被量化**——wl2"target metric"≈ Grace 三把尺子

**Grace V2 领先处**（已落地验证）：四层记忆+检索（实测 R@5 0.96）、LoRA 人格轨（比全量 SFT 轻 1000 倍）、三层情绪融合、快慢双路径+诚实失败、90 天压力测试实证、单模型资源预算、一致性加固

**wl2 方案领先处**（Grace 开放问题）：
1. **对抗训练**（历史书籍上标注模型 vs 预测模型）——Grace 无此机制
2. **显式注意力生成**（对话前生成注意力+主观判断）——Grace 用规则路由替代
3. **暗注意力学习**（穷举没说出口但影响判断的想法）——Grace 只有显式心态注入
4. **全量 context libraries**（无检索，全量给模型）——Grace 用检索省 token，未尝试全量

**后续可吸收**（Grace V2 候选改进）：
- ✅ **显式注意力生成**（M7 已实现 2026-08-27）：`engine/attention.py` —— 情绪显著度 × 记忆关联度共同生成注意力（salience/mood_ctx/memory_links/attention_text），正是"情绪系统配合记忆系统"完成
- ✅ **模型自激发**（M7 已实现）：`engine/self_activation.py` —— 基于显式注意力由**模型自己决定是否启动**（attention_driven/mood_driven/memory_driven 三源 + decide_fn 可接 27B 自决），不单单由对话启动；行动复用 M4 分级（L3→人审）。测试 8/8
- ⬜ 对抗训练（标注模型 vs 预测模型，历史书籍语料）——仍开放，建议 M8
- ✅ 暗注意力 → 双图谱暗边（2026-08-28 已实现 mood_graph edge_type=hidden + query_hidden + 幻觉守卫）（"没说出口的顾虑"注入实验）——仍开放

### M7b 双图谱耦合摄入（2026-08-27 用户洞察，已落地）
> 背景：正式 L2 图谱是事实侧，情绪在提炼时被丢掉（wechat 摘要去情绪化 → mood_driven=0）。
> 方案：摄入事件时**并行生成两张图谱**，共享 event_id/entity 耦合——
> ① 记忆图谱（事实侧：实体/关系）② 情绪图谱（感受侧：实体↔情绪边）。
> 查询实体 = 记忆事实 + 情绪历史（考试 → 事实 + [低落0.7@8-27]）。

- ✅ `engine/mood_graph.py`：mood_graph 表（entity/mood_label/intensity/ts/event_id 耦合）+ `dual_graph_ingest`（双图谱并行）+ `dual_query`（耦合查询）+ `entity_of`/`mood_label_of`
- ✅ 测试 8/8（考砸→考试实体+低落 / 奖学金→兴奋 / 耦合查询 / attention 引用情绪史 / 情绪持久化）
- ✅ 真实 wechat 演示：奖学金真香→兴奋(0.6)，情绪图谱保住（对比旧管线 mood_driven=0）
- 正式系统优化点：夜班摄入时并行写情绪图谱（保留 sentiment 标注）

### M7c 双图谱「呼应机制」（2026-08-27 用户：钥匙独立但需呼应 = 杏仁核×海马体）
> 神经科学映射：杏仁核(情绪)×海马体(记忆) 独立存储 + 时间/唤醒调制耦合。五机制全部落地：
1. ✅ **情绪强度调制记忆权重**（高唤醒→记忆强化）：ingest intensity 写情绪边，查询加权
2. ✅ **情绪一致检索线索**（mood-congruent）：`dual_query(entity, mood=当前心态)` → 情绪相近边 `congruent` 加成重排（开心时易想起开心事）
3. ✅ **情绪衰减内容永存**（fading affect bias）：负面边 τ=15 衰减快、正面 τ=60 慢；事实永存（L0 已做）
4. ✅ **事件团簇时间轴**：`query_event(event_id)` → 同事件多实体成簇（ev-YYYYMMDD 时间轴）
5. ✅ **独立存储 + 回固化重估**：两表独立（钥匙独立✓）；`reevaluate()` 事件重访时以新心境重估情绪，内容不丢

### M7d 真人思维补全（2026-08-28 用户：1-4 都要，2/4 优先）
> 对比真人思维 16 组件：Grace 覆盖 11，补 5 项高阶认知（元认知/ToM/反事实/自传体/关系动态）。
1. ✅ **ToM 心理理论**（`theory_of_mind.py`）：推断主人状态（情绪/需求/打扰意愿）→ 接入自激发 `decide(tom=)`——社交邀约+主人平静 → **不打扰**（修复话痨）；作业+焦虑 → **提醒**。决定是否主动找主人的关键。
2. ✅ **L3 升级：自传体叙事矩阵**（`autobiography.py`）：L3 从纯文字 → **矩阵**（事件×人物×实体×情绪×关系×自我评价，可切片/可叙事），结合双轨（记忆侧事件 ↔ 情绪侧情绪边）。`narrate()` 生成「我的故事」。
3. ⬜ 元认知自我反思（最难，待做：夜班加"反思我的反应"）
4. ⬜ 反事实/想象（最难，待做）
5. ⬜ 关系动态（信任/亲密度演变，待做）

### M7 自激发管线（已落地）
```
事件/对话 → 显式注意力(情绪×记忆) → 自激发评估(三源触发+激活分) → 模型决策(decide_fn)
         → 分级放行(L1/L2 自动, L3 人审) → 主动行动/留痕
```
示例：「考砸了」+ 低落 + 记忆关联 → 显式注意力"雷姆注意到主人心情低落…" → 自激发激活 → 主动关心（L1）；「数学作业明天截止」→ 记忆驱动 → 主动提醒。
