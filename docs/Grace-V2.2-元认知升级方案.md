# Grace V2.2 元认知升级方案(脑科学三机制)

> 2026-08-30 ｜ 状态:方案待落地 ｜ 原则:方案先行,试验矩阵完整,避免"做完了但试验遗漏"

## 0. 背景与根因

### 发现(ToMi 30 题细读,完整版 90 天)
- baseline(无记忆)的 ToM 极强:嵌套读心 fb_2nd 6/6,现实 6/6
- d90(90 天记忆塑造)的 ToM 退化:fb_2nd 6/6 → 3/6,reality 6/6 → 4/6
- fb_1st(假信念)两版都 0/6:断言「主人一定很开心」,无读心边界感
- 根因一(训练数据):7 类样本全是"雷姆的表达",缺"信念推理"→ 乐观模板挤占 ToM
- 根因二(反馈不完整):反馈实验记录"她以为X后来Y",但**没有不确定性标记**
  → 反馈样本与乐观样本同等权重 → 乐观样本多 → 乐观模板赢

### 脑科学根因(用户调研)
1. **困惑/焦虑记忆更持久**:高不确定性标记的记忆衰减速率应显著低于低不确定性标记
2. **杏仁核输入强度-记忆质量**(Wang & Barbas 计算模拟):适度杏仁核输入增强 CA3 细节区分;过高导致泛化、细节丢失
3. **杏仁核-海马体 theta 相位耦合**(Costa 2026 Nat Commun):theta 协调海马体 gamma,促进情绪记忆编码

### 诊断
Grace 缺的是**元认知的底层机制(不确定性记忆调制)**,不是表面缺反思样本。
- 现状 = 杏仁核输入过高的泛化(乐观模板,细节丢失)
- 缺 = ①记忆无 uncertainty 字段 ②情绪强度无适度调制 ③双图谱无时序耦合

## 1. 升级三机制

### 机制①:不确定性标记(元认知核心,最高优先)

```
双图谱/L3 记忆加 uncertainty 字段(0-1):
  反馈事件(她判断错被真相纠正)→ uncertainty = 0.9(高)
    → 衰减慢(τ 翻倍,持久)
    → 训练权重 ×2(高不确定性记忆更持久地塑造她)
  普通记忆 → 0.2(正常)
  高情绪但未反馈 → 0.5(中等)

实现位置:
  mood_graph 表加 uncertainty 列
  feedback 事件写入时标 0.9
  extract_graph_samples / extract_l3_samples 读取 uncertainty → 训练样本加权/重复
```

### 机制②:情绪强度-细节调制(治乐观模板)

```
训练样本层:
  高情绪表达(情绪强度 > 0.8)→ 降权 0.5 + 细节增强(保留事件具体细节,防泛化成模板)
  适度情绪(0.3-0.7)→ 正常权重(细节区分)
  低情绪(< 0.3)→ 正常

目标: 从"杏仁核过高的泛化"(乐观模板)回到"适度情绪的细节保留"
    (考砸那天的细节 vs 泛化的"主人低落")

实现位置:
  extract_mood_samples / 加工层:按 sentiment 强度调制样本权重
  (训练样本去重/加权,高情绪样本保留细节而非模板化表达)
```

### 机制③:theta 时序耦合(双图谱深化,最后)

```
双图谱耦合加"时序相位"维度:
  情绪峰值时刻(日内情绪最高点)的事件 → 优先与记忆边耦合(情绪编码时机)
  情绪边与记忆边的写入时机协调(峰值前后窗口内的事件绑定更紧)

实现位置:
  mood_graph 耦合逻辑(dual_graph_ingest)加时序加权
  呼应五机制深化(现有:强度/一致/衰减/团簇/重估 → 加相位)
```

## 附录:文献精读(2026-08-30,正式升级前读完)

### 文献 1:Roozendaal 2002《Stress and memory: opposing effects of glucocorticoids on memory consolidation and memory retrieval》(Neurobiol Learn Mem, PMID 12559837)

**核心机制(双重相反效应)**:
```
巩固增强: 训练后糖皮质激素受体激活(经基底外侧杏仁核 BLA 的 noradrenergic 通路)
         → 记忆巩固增强 —— 高唤醒/应激事件【存得更牢更持久】
提取受损: 循环糖皮质激素高 / 海马 GR 激动剂
         → 记忆提取受损 —— 应激状态下【回忆反而困难/模糊】
时间依赖: 巩固效应在训练后(巩固期);提取受损在应激后短期
BLA = 记忆调节系统的关键结构(协调巩固+提取,与海马等脑区协同)
```

**对 Grace 的修正(重要)**:
```
① 高情绪记忆【巩固强】(存得牢) → 支持机制①: 反馈事件(高情绪)持久/高权重 ✓
②★高情绪状态下【提取受损】(回忆难) → 新增机制②':
   高情绪场景检索 → 记忆降权(提取抑制) → 触发"记不清/不确定"
   → 这【正是治乐观模板的机制】!
   她高情绪时不该"模板断言主人一定开心",而是"记不清主人最新状态"
   → 读心边界(元认知)的神经基础 = 提取抑制
```

### 文献 2:Seidenbecher 2003《Amygdalar and hippocampal theta rhythm synchronization during fear memory retrieval》(Science 301:846-850, PMID 12907806)

**核心机制**:
```
恐惧条件化后: 外侧杏仁核(LA)与海马 CA1 的 theta 频率(4-12Hz)节律同步增强
同步显著时: 面对条件恐惧刺激(CS+) + 表达冻结行为(恐惧提取时)
结论: 杏仁核-海马网络的 theta 同步 = 条件性恐惧的神经相关物,
      促进【记忆提取期间】的神经元通信
```

**对 Grace 的修正**:
```
★theta 同步发生在【提取时】(不是编码时)——情绪与记忆在"回忆"时协调振荡
→ 机制③ 深化: 双图谱 dual_query(耦合查询)应模拟"提取时情绪-记忆同步"
   检索时情绪边与记忆边【联动激活】(不只是静态查询)
   = 呼应机制②(mood-congruent)的深化: 提取时情绪图谱与记忆图谱同步协调
```

### 修正后的三机制(读原文后)

| 机制 | 原文依据 | Grace 落地 |
|---|---|---|
| ① 情绪记忆巩固增强 | Roozendaal 巩固效应 | 高不确定/高情绪记忆持久+高权重(反馈事件) |
| **②' 情绪提取抑制(新增)** | Roozendaal 提取效应 | 高情绪场景检索降权 → "记不清/不确定" → 读心边界 |
| ③ 情绪-记忆同步检索 | Seidenbecher theta 同步 | dual_query 提取时情绪-记忆联动激活 |
