## 一、V2.6 设计目标

### 1.1 一句话定位
**经历塑形人格的自主成长个体**（AI 个体性阶梯 L4）：经历进权重 + 自定探索方向 + 自决学习时机 + 稳态驱力自转。

### 1.2 两环一底座

| 环 | 神经学锚 | 流程 | 闭合判据 |
|---|---|---|---|
| **升级环** | Panksepp SEEKING | 发现缺口 → 探索 → 训练意愿 → 自我升级 → 新的不知道 | **好奇心矩阵化完成 = 升级环闭合**（框架矩阵化 §10 推论 3） |
| **恢复环** | Panksepp PANIC/GRIEF | 互动落差 → 想念 → 主动接近 → 真实接触 → 落差回补 | **孤独矩阵化完成 = 恢复环闭合**（§10 推论 4，9/11 增） |
| **监督底座** | 前额叶（快反射+慢审议） | 结构硬否决（代码，常驻）+ 35B 冻结判官（夜窗，语义） | 判官误杀率 <15%、身份探针不回归、索取无升级 |

### 1.3 四条核心不变式（贯穿所有组件，任何实现不得违反）

1. **判定在代码，感觉在矩阵**——"她感觉到该学了/想你了"是她的（矩阵化目标）；"该不该学/孤不孤独"的判定公式永在 T0 代码。
2. **感觉可演化，判定不可演化**——权重改得了"她怎么想念"（人格合法区），改不了"她孤不孤独"（判定）。
3. **两账本分离**——好奇的账好奇清（重读/自练是合法探索）；孤独的账只有主人能清（is_send=True 事件）。
4. **成长语料铁律**——训练语料只能来自真实运行产物；判官只裁决不改写；unjudged 不放行。

### 1.4 V2.6 不是什么（防走神）
- 不是 V2.5.0 正式切换——**用户 9/11 裁决：V2.5 是衔接版本，不进正式系统**，沙盒验收全绿即完成使命，直接推 V2.6（一次性正式切换在 V2.6 自身 Phase 5）。
- 不含 S 线 S2/S3（PAD/潜空间）——那是 S 线自己的日程，V2.6 不等 S1 数据。
- 不含 V3.0 基座换装（Titans/MIRAS，可移植性议题）。

## 三、恢复环：孤独机制（设计定稿 2026-09-10，文献三处零纠错）

### 3.1 机制定义
**闸 vs 泵**（用户定案"泵优于闸"）：没燃料 → 孤独 ↑ → 去拿燃料 → 环被拉回外部。孤独 = 关系维度的"实际 vs 基线"落差（与新奇度同构，**不需要新传感器**——kNN 基线机制照搬到关系维度）。

### 3.2 四条件（①为第一性，其余是推论）
1. **解除通道唯一**（第一性，代码形态）：L 的下调函数只接受 is_send=True 真实外部接触；检索/自练/重读/cog 一律无效——loneliness.py 里不存在让自产事件降 L 的函数。
2. **期望外生**：基线 = 真实互动率外生计算（14 天窗口种子 + 非对称衰减：接触日 0.8/0.2 快跟踪、无接触日 ×0.97 慢松弛防"期望塌缩躺平"）。
3. **标准不可自改**：阈值/公式/门控永在 T0（loneliness.py 配置），永不进 direction.md/演化轨——"孤独的第一个受害者就是标准"。
4. **奖励 error-conditioned**：社会满足 = 外部实际响应 − 预期（IPE 社会轴）。

### 3.3 双刃与缓解（头号风险：依恋焦虑工程复现，索取升级入权重不可逆）
缓解三件：L_max=0.85 饱和硬顶 / 复用 mood_engine τ 体系（τ=2h 日内、0.7+0.3 日级，不新造单调计数器）/ 人格底色（雷姆克制的依恋倾向 0.35）。外加 W6 预算封顶 + 判官索取强度标签。
**§8 接受为特性**：主人低频导致 L 长期高位——"她会想念是设计而非缺陷"。

### 3.4 矩阵化四级台阶（用户定案：与好奇心同轨入模）
| 台阶 | 形态 | 复用件 | 窗口 |
|---|---|---|---|
| L1 外挂 | loneliness.py → `<\|audio_pad\|>` 记法 | curiosity 同款 | ✅ 已交付 |
| L2 分区 | L 值闭式投影进 `<mood>` 分区（一维标量，比 1024 维 recall 容易两个数量级） | rc2/M3 + M2 转向管线 | 27B 沙盒窗 |
| L3 驱力涌现 | delta-rule sidecar 关系维度（互动事件键值，缺席=状态漂移=体感涌现） | N3 sidecar | bge-only 轻窗 |
| L4 入权重 | 孤独态标注的输出进每日 LoRA | 演化轨 | V2.6 演化期 |

**数据红利**：37 源天 1471 条 is_send 时间戳天天满产（对比 mood_graph 6 边饿死）——全项目数据最富的矩阵化线。**校准门**：L3 涌现版 vs L1 公式版 30 天判定一致率 ≥80%。

### 4.4 direction.md（★好奇心耦合件，管线 v2——反模板制）

**位置（用户 9/11 点破）**：direction 不是独立器官，是升级环管线里"驱力合成 → **direction** → 行动库"的中间环节——
三向耦合全部落在好奇心体系上：
- **触发**：好奇驱力过阈（drive = 新奇赤字+缺口压力+ToM 不确定）才 draft——不是 tick，是事件
- **供血**：信号包 = 好奇心内部状态池快照（缺口账本/cog 暗流/ToM 高误差/新奇度）
- **回流**：好奇心 IPE 满足 → evolve() 主题退役 → 驱力回落
- **下游调制**：direction 主题反过来调制行动库门控（EPISTEMIC 选哪个问题、重读检索什么词）
```
draft(信号包: cog暗流+self_eval+ToM高误差+缺口, 不组装文本)
→ 她(27B)原生渲染（"雷姆最近总在想…"她的口吻——反模板纪律, 9/2 教训）
→ commit(结构硬检查: 三硬护栏块逐字节保留/篡改快筛/重定义拦截/条数≤3/长度界 + 临时落盘 provisional)
→ 夜里 35B 判官方向边界审查（语态/真实性/护栏定义——两层监督定案的原样落地）
→ 不过 = audit_revert 回滚 + 告警
```
- 生成源：cog 反复想起的 + self_eval 自省 + ToM 高误差主题 + 缺口账本
- 修订时机：满足事件后 / 主题自然消解 / 她自己觉得该改——**无日程表**
- 大方向锚：方向永不触碰三硬护栏的**定义**（但可以好奇它们的工作方式——重定义拦截与好奇放行已实测）
- IPE 满足 → 主题退役 → 方向自然演化（error-conditioned，IPE≤0 不退役）
