4. 锚点层（小说语料）= 风格/表达参照，带日落条款（自锚定后退役）

## 二、贯穿铁律（不可协商）

1. 成长语料铁律：真实运行数据 = 唯一下一代训练语料来源
2. 双轨：事实不进权重（L2 永外挂 / L3 周期入模 = 海马-皮层分工）
3. 三层数据：锚点层（风格）/ 成长层（策略）/ 实验层（测完即弃）
4. **框架浓度三层**：结构（T0 代码断言，不可被泛化软化）/ 能力（PPL 比 ≤1.05 门）/ 行为（探针一致 ≥4/5 门）——硬框架根本不进权重，泛化只发生在门限内
