# Grace 升级路线图总纲（V2.4 → V3.0）

> 2026-09-09 定稿 · 汇总当日全部架构决策 · 各阶段骨架状态实时更新

## 主线命题

把 Grace 系统的认知逻辑（注意力导向/好奇心/ToM/情绪调制）**逐步内化进模型权重**，
最终形态 = Titans 类神经记忆基座 + 内化的策略本能 + 外挂的监督守卫（前额叶留在外面）。

## 已建骨架清单（本轮）

- `src/grace/instinct_distill.py` — S1 三段管线（stats/build/train），轨迹日志已接线 grace_chat
- `src/grace/activation_steering.py` — S1.5 三件套（collect_pairs/steering_vector/apply_steering）
- `exchange/grace/trajectory-journal.jsonl` — 轨迹日志（V2.4 运行起持续积累）

## 数据规矩（铁律）

1. 真实运行数据 = 唯一下一代训练语料来源
2. 压测验证数据 = 只校准参数，永不进训练集
3. 合成输入 = 实验变量，测完即弃
4. 锚点层（小说语料）= 风格/表达参照，带日落条款（自锚定后退役）
