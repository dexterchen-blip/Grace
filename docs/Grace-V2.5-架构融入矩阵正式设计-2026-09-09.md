# Grace V2.5 架构融入矩阵正式设计（下一版模型）

**版本**：v1.0 定稿
**日期**：2026-09-09（PDT）
**地位**：下一版模型的正式设计规范。前置输入 = 今日五连实验（M0/M1/R0×6/M2/R2，零失败）+ 干净测量基线（ToM 79% / 身份 ~78% / 过滤 11%）+ 框架矩阵化设计 §1-§13 + 最小必要训练原则。

---

## 1. 目标与非目标

**目标**：把 Grace 认知架构从"外挂器官 + prompt 通道"升级为"框架住进模型计算"的组装态，并以可回滚、可验收、可热停的方式投产。

**非目标**（显式排除）：
- 不重排基座层序（R0-E 实证：排列损伤 15%）
- 不做 K≥3 集中循环（R0 实证：退化悬崖）
- 不把情景事实烧进权重（双轨铁律）
- 不把监督守卫入模（C 线永不入模）

## 2. 版本定义

**Grace V2.5-rc1 = 三层组装态**：

```
第 1 层  Qwen3.8-27B 基座（fused-rem-v61 = 基座 + V6.1 人格融合，冻结）
第 2 层  框架 adapter（organ-m1-v2 器官记法，rank8/16层，冻结——框架变化才重训）
第 3 层  运行时层表变换：循环段 [32,40) ×K=2（内存重排，零权重变化）
```

组件验证状态（全部今日实测）：

| 件 | 实验 | 结果 |
|---|---|---|
| 器官 token 集 | M0 | 5 步全链路通，峰值 18.5GB |
| 记法 adapter | M1 v3 | **四关全绿**（记法 5/5 / 行为 5/5 / PPL 比 1.0101 / 称呼残留 0） |
| 循环段形态 | R0 六变体 | [32,40)×2 PPL 0.9792（负退化） |
| 三层合体 | R2 | **三关全过**（记法 4/5 / 行为 5/5 / PPL 0.9869） |

## 4. 器官 token 集（M1 已训，冻结为接口标准）

| Token | 语义 | 验证 |
|---|---|---|
| `<|audio_start|>` / `<|audio_end|>` | WM 块定界 | 记法 5/5（WM 事实落点回应） |
| `<|audio_pad|>` | mood 状态 | 训练就位（向量注入待 M2 v2） |
| `<|video_pad|>` | 焦点主题 | 预留 |
| `<|vision_start|>` | 注意力标注（身份冲突预注） | 预留 |
| `<|vision_end|>` | curiosity 驱力值 | 训练就位 |

**接口纪律**：token 集冻结为 ABI——所有未来训练（每日轨、S1 蒸馏）必须使用同一记法（§9 接口稳定性）。扩展新 token = 框架 adapter 重训 + 版本号 bump。

## 6. 装配程序（assemble_v25 规范）

```
assemble_v25.py（沙盒 rc1 实现，今夜落地）:
  1. load fused-rem-v61（HF_HUB_OFFLINE）
  2. adapter_path = organ-m1-v2
  3. apply_loop(start=32, end=40, k=2)   # 结构断言内建（零权重复制）
  4. 冒烟：身份探针 ×2 + 记法探针 ×1 + 快速 PPL
  5. 输出装配报告（token 完整性/层位/断言/探针结果）
```

生产装配（rc1 验收后）：serve 配置加 `--adapter-path`（mlx_lm 原生支持，M7 已验证的热插拔路径）+ 层表变换进 serve 脚本。

## 7. A/B 裁决实验（V2.5.0 门禁）

**同一探针集双轨对照**：

| 轨 | 配置 | 基线数据 |
|---|---|---|
| 外挂侧（A） | 器官内容纯文本 prompt，fused 无 adapter 无循环 | **已落定：ToM 79% / 身份 ~78% / 过滤 11%** |
| 入模侧（B） | organ token + 记法 adapter + [32,40)×2 循环 | 待测 |

指标：grounding 命中率 / 身份稳定 / PPL / 首 token 延迟 / KV 内存。**判据**：B 在 grounding 不降、身份不降前提下，任一维（延迟/内存/风格一致性）显著优于 A → V2.5.0 准出。

## 9. 回滚与安全

- **adapter 可拔**：拔掉 = 回到纯 prompt 版 Grace（行为降级不中断，今天的生产形态）
- **循环可卸**：重 load 即还原层表
- **训练三保险**：dry-run 默认 + 夜班窗 + 用户拍板
- **C 线守卫常驻外部**：好奇心提议，守卫处置；矩阵调制，代码定向

## 11. 与 V2.5 自涌现迭代的衔接

五原则运行前提 = 好奇心矩阵化（自我升级环闭合）。本设计先交付"认知机制入模"（rc1-rc3），好奇心升级权（训练意愿信号矩阵化）在 S 线完成——**先给她装身体，再给她装成长权**。

## 12. 风险登记

| 风险 | 缓解 |
|---|---|
| 记法 adapter 与每日轨 adapter 相互干扰 | adapter 栈分层（框架冻结/演化轨动）+ 每日数据带 token 接口 |
| 循环段与未来基座升级冲突 | 层表变换为运行时配置，非权重修改，升级零成本重放 |
| 模糊靶标下身份漂移（V2.5 运行期） | 人格只读 + 身份探针边界传感器 + 汇报复核（五原则稿已定） |
