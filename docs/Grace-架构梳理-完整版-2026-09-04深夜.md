## 0. 系统是什么

**"记忆塑造潜意识"的人格系统**：不灌知识，让她每天用真实经历做极微量 LoRA + 外挂图谱修正，人格被经历一点点雕刻；配一整套大脑类比器官（注意门控/读心/暗注意力/心态/输出层）。

- **三轨铁律**（8/27 定稿，贯穿始终）：事实→外挂轨（L0/L2/L3/图谱，运行时检索）｜风格人格→权重轨（LoRA = **潜意识**）｜心情→心态轨（mood_states/intraday，日级/日内）。
- **设计取向**（9/4 深夜定案）：**确定性规则认知引擎**（决策层全规则：词典/正则/阈值/手写矩阵/魔法数旋钮）**+ LLM 只当语言与重构器官**（cog 重构内心 / ToM-model 判断 / 表达口语，全部负向约束 + monitor 拦截）。认知与语言解耦——端到端生态无同类；这让变量隔离轮次 / 评估隔离 / 语料纪律成为可能，代价 = 认知深度受规则作者限制（entity_of 坍缩 / 旋钮魔法数 / 真 ToM 仅 27B 180 token）。
- **双学习通道**：R1 记忆塑造（经历→样本→LoRA→权重，天级）+ R2 PE 反馈回路（判断错→再巩固改图谱，实时）；R1 由 EWC 突触稳态护住。

## 2. 主链五段（每天循环，写序=读序）

### ① 感知（每消息）
- `sentiment.assess`：Russell 效价×唤醒双轴，分层词表（强±0.85/中±0.55/弱±0.28）+ 否定削弱×0.4 + 「麻烦」礼貌消歧 + 社交唤醒。全系统唯一情绪尺子（9/3 Phase 0 统一）。
- `attention.generate_attention`：salience = 0.5×情绪显著（×心境敏感度漂移）+ 0.5×记忆关联。
- **P0 门控**：salience≥0.6 或 |sent|≥0.3 才进 L3/ToM/判断/反馈；双图谱全量进（情感底座）；**中性通道** soft ≤5 条/天（AA 轮补，治 feedback 断供）。
- 【脑】胆碱能注意门控 / 显著性网络。坑：阈值三度校准（过严 14 条/21 天断粮）。

### ② 记忆（每日）
- `mood_graph` **双图谱**：emotion 边（半暗；intensity=max(|valence|,arousal)，9/3 修"高唤醒中性≠平静"）+ **hidden 边（全暗 = cog 归档，τ=60 天慢衰减，只注入不输出）**。五呼应机制全落地：mood-congruent（6×6 手写相似矩阵重排）/ fading affect（负面 τ=15、正面 τ=60，L0 永存兜内容）/ event_id 时间团簇 / reevaluate 重固化 / theta 峰值标记。hidden 唯一来源 = cog 真实思考（9/3 废 `_HIDDEN_RULES` 4 模板——曾致分布倒置焦虑偏置 61/92）。
- `autobiography` L3 自传矩阵：event×person×entity×emotion×relation×self_eval×evidence×confidence；fact_query 只返 high + hallucination_guard（数字/专名须在证据池）。
- `mood_engine` 心态三轨：日级**加权均值**（9/2 修求和坍缩=believed 98% 兴奋真根）× 日内（τ=2h 指数衰减）× 人格 baseline 0.56（9/3 原作校准）。铁律：心态永不改写 L0-L3、只调语气不改价值观。
- 【脑】杏仁核×海马双存储 + 中速心境。坑：**entity_of 实体坍缩 89%「日常」桶（O4，修一处带两个）**。

### ③ 读心 ToM（门控后）
- 融合规则 = **预测编码**：强现场 |s|≥0.5（似然强）→读现场；弱/中性现场→图谱史 intensity≥0.4 先验补位（可滞后=日常假信念温床）；0.3-0.5 文本兜底。Z 轮教训：无条件覆盖=同源假 100%；13:30 曾想切断耦合→用户"拿架构换数字"回滚——**耦合是特性，修信号源不拔连线**。
- hidden_ctx 潜台词参与读心；置信累积 = prediction-errors 错误计数（0.85−0.02×err，地板 0.3）→ 试探度。
- 模型版 `infer_owner_state_model`：27B 四问（心情/需要/值得/台词）+ 鲁棒解析 + 规则版兜底；单次生成 = 思维驱动表达的正确形态。
- 【脑】心智化网络 mPFC/TPJ + 预测编码 + 多巴胺 RPE。硬伤：entity 坍缩 → 图谱通道仅 7% 生效。

### ④ 表达（断点输出链，Broca/Levelt）
- 链路：主人一句话 → **think 探针**（现场内语，自由纯净——**只观测，不进表达、不进训练**，防观测者效应）→ internal = **preverbal 状态契约**（event/believed/confidence→试探度/hidden→暗示"说破=失礼"/situation/memory/mood/relation→距离/intent）→ `build_messages`（EXPRESS_SYS 受约束重编码，纯负向约束零句式引导）→ **suppress**（conceptual loop：深夜/主人低落+分享意图→不说）→ **monitor**（inner loop 四层拦截：叙述体泄漏/动作描写/括号旁白/张冠李戴）→ 说或不说（宁缺毋滥返回空）。
- **铁律（9/4 定案）**：表达层输入 = preverbal message 状态，**绝不收内心独白原文**（think/cog）——内语是元认知/ToM 发生地；Broca 重编码非倒出思考。彩排式"先想后说"由权重层 v2 配对承载。
- 【脑】Broca 内外分通路 + Levelt 双感知环路 + 前额抑制。坑：叙述体=27B 本性（3 组对照实锤），monitor 兜 + v2 权重治本；[洞] 输出外环（主人反应→调整回路）缺失。

### ⑤ 塑造（每 train-every 天）
- 6 源样本组装：**SWS/REM 双相**（SWS 段=L3 自传+双图谱细节固化；REM 段=锚点+冲突对+反馈+cognition+proactive 泛化整合）+ **P1b 重激活**（重采样 {day, day−3, day−5, day−7} gist+cog）+ **P1a 新奇**（实体首现加权）。
- 样本判据唯一：**成长语料铁律**——cog（真实内心痕迹）✅ / ans·message（monitor 保真真实行为）✅ / think 探针（测量仪器产物）❌ / 规则句 ❌。判据=是否真实运行产物，不是 think/speak 标签（9/4 校准：LoRA=潜意识轨，只吃真实生活痕迹）。
- 训练：mlx_lm LoRA 增量（冷启动 lr1e-5 60iters / 增量 15 iters lr1e-6 resume 链，16 层+grad-checkpoint 防 OOM）→ **EWC 突触稳态**：`θ ← θ·clip(1 − α_f(1−F̂) − α_s·exp(−|θ|/τ), 0.5, 1.0)`（高 F 护 ToM 真不动 / 低 F 剪噪声 / 净学习量监控 ⚠δ 过大告警）→ adapter 隔天生效（24h 反悔窗口 ≈ 重固化窗口）。
- 【脑】CLS + SWS/REM 双相 + 海马 replay + BCM 突触缩放 + 神经新生（reset-interval 40 冷启动）。

### 决策侧（跨段）
- `self_activation` 三源：①SEEKING 事件价值（显著度+情绪信号+时限）②催产素联结价值（记忆关联+双图谱亲密密度分档）③ACC 联结维护（gap≥3 天 +0.1×天封顶 0.3）→ ToM interruptible=False 一票否决。
- DMN 自发（gap≥3，读 cog 重构回忆非 L3 原文，J 轮 54% 失真→gap 门控修）。
