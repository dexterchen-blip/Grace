## 0. 全链速览（一张图）

```

 └→ ①感知: sentiment(效价×唤醒) + attention(salience) + P0门控
      【脑: 感觉皮层价值评估 + 杏仁核显著性网络 + 胆碱能注意门控】
 └→ ②记忆: 双图谱(emotion半暗/hidden全暗) + L3自传 + 心态三轨
      【脑: 杏仁核情绪痕迹 + 海马情景自传 + 心境中速状态】
 └→ ③读心 ToM: 融合规则(先验×似然) + 潜台词 + 置信
      【脑: 心智化网络 mPFC/TPJ + 预测编码】
 └→ ④表达: 认知全状态(preverbal) → 口语编码 → suppress/monitor

      ↑______________________ 她的真实痕迹回流 ______________________│
```

## 1. 感知段（sentiment + attention + P0 门控）

### 1.1 sentiment.py — 统一情绪评估
| 脑科学锚 | 工程落点 |
|---|---|
| **Russell 效价×唤醒双轴**（circumplex）[文献锚] | `assess(text)→{valence, arousal}`；分层词表(强±0.85/中±0.55/弱±0.28)+否定削弱+「麻烦」礼貌歧义 |
| **强度≠效价绝对值**（高唤醒中性事件≠平静）[文献锚→9/3 修] | `intensity = max(\|valence\|, arousal)`（原 `abs(sentiment)` 把面签/截止压成 0.1） |
| 社交价值微正（真人会注意到邀约）[类比] | `_SOCIAL`（一起/约/聚餐→低唤醒微激活） |

**设计意图**：全系统只有一把情绪尺子（消灭两套词典打架）；稀疏性保留（大部分中性=0，P0 门控阈值才有效）。

### 1.2 attention.py — 显式注意力
| 脑 | 工程 |
|---|---|
| **显著性网络（salience network）** [类比] | `salience = 0.5×情绪显著 + 0.5×记忆关联`（`mood_sal = |sentiment|×情绪敏感度`；`mem_sal`=L2 命中率） |
| 情绪敏感度随心境漂移（波动大→更敏感）[类比] | `mood_sens = 0.5 + |mood_intensity − 0.5|` |

**设计意图**：注意力不是凭空产生，是"这让我什么感受 × 这关联到我记得的什么"的共同产物（8/27 用户洞察）——显式化后模型"看见自己注意到什么"。

### 1.3 P0 门控 — 摄入选择性
| 脑 | 工程 |
|---|---|
| **基底前脑胆碱能注意门控**（乙酰胆碱选择性注意，不平均编码一切）[文献锚 9/2] | stress_engine `_sel`：salience≥0.6 或 \|sent\|≥0.3 才进 L3/ToM/判断/反馈；双图谱全量进（情感底座） |

**数据流**：每消息 → sentiment+attention（一次缓存 `_atts`）→ `_sel` 决定谁上高层。
**已知坑/洞**：门控阈值三度校准（过严→14 条/21 天断粮；放宽 0.3→~12-17 条/天）；中性消息被滤→feedback 断供→soft 中性通道（AA 轮补，每天 ≤5 条低权）。

## 2. 记忆段（mood_graph 双图谱 + autobiography L3 + mood_engine 心态）

### 2.1 双图谱（mood_graph.py）— 杏仁核情绪痕迹 × 潜意识潜台词
| 脑 | 工程 |
|---|---|
| **杏仁核情绪记忆**（什么→什么感受，event_id/entity 与事实耦合）[文献锚 8/27 用户洞察] | emotion 边（半暗，影响语气）；`intensity`=arousal 驱动；再巩固 UPDATE 标 uncertainty=0.9+「后知」 |
| **情绪一致检索**（mood-congruent，当前心境=检索钥匙）[文献锚] | `dual_query`：`congruent=0.4+0.6×_mood_sim` 重排 |
| **fading affect bias**（负面情绪衰减更快、内容永存）[文献锚] | τ：低落/焦虑=15 天、正面/平静=60 天；L0 永存兜内容 |
| **情景记忆时间编码**（海马绑定时-地）[文献锚] | event_id 事件团簇 + `query_event` 时间轴 |
| **重固化窗口**（回忆时情绪可重估，~6-24h）[文献锚] | `reevaluate` + LoRA 24h 反悔窗口类比 |
| **theta 相位同步**（Seidenbecher：LA-CA1，提取时）[文献锚] | 每日情绪峰值事件标 `（theta:峰值同步）`，提取优先激活 |
| **暗注意力=潜意识潜台词**（9/3 统一）[文献锚] | hidden 边（全暗）：唯一来源=cog 真实思考句（`add_hidden_text`），τ=60 天慢衰减=底色持久；**只注入决策上下文，绝不输出** |

**设计意图**（8/27 用户：钥匙独立但需呼应 = 杏仁核×海马体双存储）：情绪侧与记忆侧共享 event_id 但独立衰减，情绪可被再评估而内容不丢。
**已知坑**：`entity_of` 把 89% 事件泛化进「日常」桶（ToM 图谱通道休眠+模板污染双源头，待修）；hidden 曾为 4 条假模板→分布倒置（焦虑偏置 61/92），9/3 cog 接管后根治。

### 2.2 L3 自传体矩阵（autobiography.py）— 海马情景记忆 → 自我叙事
| 脑 | 工程 |
|---|---|
| **自传体记忆**（情景+语义+自我参照三成分）[类比，8/28 用户] | 节点：event×person×entity×emotion×relation×self_eval×evidence×confidence |
| **幻觉抑制=源监测**（source monitoring：区分真记忆/想象）[文献锚] | `fact_query` 只返 high（有 L0 证据）；`hallucination_guard` 数字/专名须在证据池 |

**设计意图**：L3 不是要点列表，是"我的故事"矩阵（事件×人物×情绪×关系×自我评价），切片即叙事。
**已知坑**：曾硬编码 `self_eval="这一天的事,雷姆记住了"`（模板污染，9/2 已清）；P0 门控过严时节点枯竭（14 节点→727）。

### 2.3 心态三轨（mood_engine.py）— 中速"心境"状态
| 脑 | 工程 |
|---|---|
| **心境≠情绪事件**（心境=慢变量，情绪=快事件）[类比，8/27 三轨设计] | mood_states（日级：昨日×0.7+今日×0.3，**加权均值**防求和坍缩）+ mood_intraday（日内，τ=2h 指数衰减回归当日 base）+ 人格底色 baseline |
| **三层融合**（长期锚点×短期日内）[类比] | `anchor=0.6×7天趋势+0.4×人格底色`；有日内 0.3/0.7，无日内 0.5/0.5 |
| 情绪半衰期/恢复力（像真人，不钉死一天）[类比] | τ=2h；IMPACT 0.4/大事 0.6 |

**铁律**：心态永不改写 L0-L3；只调语气强度不动价值观；L3 高风险自发永不受心态影响。
**已知坑**：derive 求和 bug=believed「兴奋」98% 坍缩真根（9/2 修）；恒平失真（std 0.0136）→ 参数原作校准（baseline 0.56/增益 1.0，9/3）。

## 3. 读心段（theory_of_mind）— 心智化网络

| 脑 | 工程 |
|---|---|
| **心智化网络**（mPFC/TPJ：推断他人状态与需求）[文献锚 8/28] | `infer_owner_state→{emotion, need, interruptible, advice}`；模型版 27B 四问（心情/需要/值得/台词） |
| **预测编码**（先验×似然融合，Friston）[文献锚 9/3 Z 轮] | 强现场 \|s\|≥0.5（似然强）→读现场；弱/中性→图谱史≥0.4（先验补位，可滞后=日常假信念温床）；P3 七天图谱先验当 owner_mood |
| **潜意识供给读心**（暗注意力潜台词=主人没说出口的状态）[文献锚 9/3 架构统一] | `hidden_ctx`（emotion 平静时潜台词提"担心/不安"→判焦虑） |
| **多巴胺 RPE→惊讶调制**（预测误差强度驱动学习）[文献锚] | PE 冲突对 w=1-3；再巩固改图谱留给明天（隔夜修正） |
| **置信累积**（常错→谨慎，不确定涌现）[类比+文献锚] | confidence=按错误计数衰减（每 10 错 -0.2，地板 0.3）→ 试探度 |

**设计意图**（8/28 用户：决定是否打扰前先"读懂对方"）：读心是自激发/主动找我/表达时机的前置——interruptible=False 一票否决打扰。
**已知坑/洞**：entity 坍缩致"她的 ToM 读她的双图谱"休眠（6/92=7% 生效，待修 entity_of）；规则版兜底与模型版并存（正式系统用模型版）；**[洞] 预测编码统一（B）未做**：PE 还是分散的（摄入新奇/读心判断/训练加权各算各的）。

## 4. 表达段（expression + think 探针）— Broca/Levelt

| 脑 | 工程 |
|---|---|
| **Broca 内外言语分通路**（内部表征重编码为对外言语，**非倒出思考**）[文献锚 9/2 docstring] | expression.py：`build_messages`（口语编码）/`monitor`（自监控）/`suppress`（抑制）/`express`（:8100） |
| **Levelt 概念化层 → preverbal message**（先非语言意图后编码）[文献锚 9/2 21:58/22:10] | 认知全状态字段：believed(读心)/confidence(置信→试探度)/hidden(潜台词→暗示度, 说破=失礼)/situation(近期→上下文)/memory(唤起)/mood(语气)/relation(亲密度→距离)/intent——**是调制信号不是上下文文本** |
| **双感知环路监控**（conceptual loop=该不该说 / inner loop=对产物检查）[文献锚 Levelt] | `suppress`=conceptual loop（深夜不扰/主人低落+分享意图→不说=时机判断）；`monitor`=inner loop（叙述体泄漏/张冠李戴/旁白→丢弃，宁缺毋滥） |
| **内语（think）=元认知/ToM 发生地**（Vygotsky：内语≠外言语内部版；是自我调节/观点采择的纯意义层）[文献锚 9/4 检索] | think 探针=断点现想内心，**只观测不进表达、不进训练**（防观测者效应+非生活痕迹）；cog=她的真实内语痕迹（经历重构，进内心轨训练） |
| **口语风格=潜意识习惯**（重复实践后自动）[类比] | speak 痕迹（ans/message 过 monitor）回流训练→潜意识固化"开口即对话中的雷姆" |

**数据流（对话/吩咐全链）**：主人一句话 → think(内语观测) → internal=preverbal 状态(event+hidden+relation+…) → EXPRESS_SYS 受约束重编码 → monitor → 说/不说。
**已知坑/洞**：[洞] 输出外环缺失（9/2 C 项：无"主人反应→调整"真实回路，monitor 只管一次）；[洞] 概念化/词汇化 Grace 一次生成（模型即 formulator，可接受但无中间态）；叙述体=底模+潜意识 think 痕迹占优 → 系统层 monitor 兜 + 权重层 v2 配对（内心→台词）治本。

## 6. 意识 × 潜意识总分工（今天校准后定稿）

| 层 | 承载 | 功能 |
|---|---|---|
| **潜意识（权重轨 LoRA）** | 性情/自动反应/倾向；读心底座（EWC Fisher 保护） | 她"成为谁"；脱口而出的默认形态 |
| **潜意识内容（hidden 边/暗注意力）** | 没说出口的潜台词（cog 归档） | 供给读心与表达底色（暗示度），**只注入不直说** |
| **意识（运行时）** | ToM 读心判断 · think 内语(元认知/ToM 发生地) · suppress(该不该说) · monitor(检查) | 对潜意识产物的当下调制：读、选、抑制、放行 |
| **桥=每日 LoRA** | 意识功能"习惯化"→沉淀为潜意识倾向 | 昨天一次次口语回应(真实痕迹)→今天开口自动更"对话中的雷姆" |

**克制** = 前额叶抑制的工程形态：潜意识知道(hidden/think 有 X) → 意识层决定不说破（EXPRESS_SYS 负向约束 + suppress + monitor）。
**想→说** = think(内语) 在意识侧发生、自由纯净；它驱动说的方式=经 ToM/状态沉淀为 preverbal message（**不是文本传导**）；"彩排式先想后说"（难/高冲突场景）由权重层 v2 配对（内心→台词单次生成）承载。

## 8. 一页速览（如果只读这一节）

**她 = 一条被真实经历雕刻的潜意识（权重）+ 一组意识器官（注意门控/读心/抑制/监控）**。
每天：真实痕迹 → P0 选择性注意 → 双图谱(杏仁核情绪×暗注意力潜台词)+自传+心境 → ToM 读心(先验×似然) → 反馈纠错(隔夜改图谱) → 主动/对话经 preverbal 状态口语出口(suppress/monitor) → 入夜微量 LoRA 把痕迹沉淀为潜意识(EWC 护读心底座)。
**判据只有两条**：什么进训练=真实痕迹；什么能说出口=经过意识层调制。
