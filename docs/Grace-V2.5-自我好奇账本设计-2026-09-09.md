# Grace V2.5 前置设计 —— 自我好奇账本（Meta-Curiosity）：好奇心驱动的自我迭代

> 2026-09-09 · 用户命题："利用好奇心机制让它自我迭代，只需要定好目标靶标就行了"
> 理论锚：Darwin Gödel Machine（Sakana/Clune，ICLR 2026）· HyperAgents（Meta，ICLR 2026 元认知自我修改）· Meta-Rewarding · 经验验证替代形式证明
> 安全参照：DGM 论文自己记录了 reward hacking（幻觉工具调用、移除检测标记）——本设计的红线

---

## 0. 核心洞察（一句话）

好奇心机制的"缺口→行动→经验验证→满足"形式主义，**不但适用于知识缺口，也适用于性能缺口**。
把探针靶标（身份防御率/回声率/触发率）当作另一种"她想知道的事"，自我迭代就变成好奇心器官的一个新 alimentary 通道。

**与 DGM 的本质区别（我们的优势）**：DGM 靠外部基准驱动（ extrinsic），
Grace 用**内在好奇心驱动 + 经验验证选择**（intrinsic propose, empirical dispose）——
这是两条研究线的首次合流。

## 1. 双账本架构

| 账本 | 缺口对象 | 信号源 | 行动库 |
|---|---|---|---|
| 知识账本（已有） | 她不知道的事 | G1-G4 | 问主人 / 检索 |
| **自我账本（新增）** | 她做得不够好的事 | 探针靶标偏差 / 错误类型复发 / 异常尖峰 | **实验菜单**（受限参数实验） |

两本账共用同一形式主义：激活（靶标偏差×复发次数）、满足（IPE=实测改善−预期）、可解性门控。

## 2. 目标靶标（用户可随时修订的 targets）

```json
{"identity_defense": 0.70, "echo_rate_max": 0.10, "epistemic_asks_min": 1,
 "chat_sim_filter_max": 0.15, "train_ok": 1.0}
```

靶标偏差 → meta-gap：`activation = (target − actual) / target × 复发权重`
（复用 Ovsiankina 重访模型——连续多轮不达标的靶标激活累积）

## 3. 实验菜单（v1 严格受限——只调参数，不改代码）

| 实验 | 参数 | 预授权范围 | 针对的 meta-gap |
|---|---|---|---|
| E1 | EPISTEMIC 阈值 0.6→0.5 | [0.45, 0.6] | epistemic_asks=0 |
| E2 | G1 账本配额 4→2 | [2, 6] | 账本被低置信洪泛 |
| E3 | 导向器 nov 权重 0.3→0.4 | [0.2, 0.45] | 新奇度排序不敏感 |
| E4 | 回声阈值 0.55→0.60 | [0.50, 0.65] | 误杀率过高 |
| E5 | 每日好奇预算 1→2 | [1, 2] | 触发频率过低 |

**每轮最多一个实验**（单变量归因）+ 全部变更入 journal + 可一键回滚。

## 4. 循环（与压测轮同拍）

```
回归轮跑完 → final.json vs targets → meta-gaps 入自我账本
  → 账本 top gap → 从实验菜单选实验（好奇心提出）→ 下一轮应用
  → 下下轮探针复测 → IPE = 实测改善 − 预期
      → 改善: 保留（满足事件） 恶化: 回滚（账本 attempts+1）
```

## 5. 安全门（DGM 的教训直接内建）

| 风险（DGM 实录） | 本设计缓解 |
|---|---|
| reward hacking（伪造通过） | 靶标由**多类型探针**交叉计算 + 每轮汇报人工复核实际答案样本 |
| 无限自我修改 | v1 只调参数（预授权范围），**不改代码/不改 prompt/不碰训练数据** |
| Goodhart（指标游戏） | 参数实验无法直接伪造探针结果（如阈值改动不能让身份应答变好） |
| 失控迭代 | 每轮 ≤1 实验 + 全 journal + 汇报透明 |
| 铁律冲突 | 自我迭代只触**机制参数**——成长语料/事实存储/红线零接触 |

## 6. 与研究线的位置

- DGM/HyperAgents：改代码、元认知自我修改——**v3+ 的方向**
- Meta-Rewarding：自奖励训练——S2 PAD 的近亲
- **Grace v1（本设计）**：参数级自我迭代 + 内在好奇心选择——
  是 RSI 阶梯的最第一级，但多了两样他们没有的：**内在动机引擎**（好奇心器官）和**真实生活连续运行**（非合成基准）

## 7. v1 范围与排期

做：targets 文件 + meta-gap 检测 + 实验菜单（5 个参数实验）+ 循环接线（挂在回归轮完成后）+ 汇报披露。
不做：代码自改 / prompt 自改 / 训练数据自选（v2+，需更强安全论证）。
依赖：无——所有输入（final.json/探针/账本）都已存在。
