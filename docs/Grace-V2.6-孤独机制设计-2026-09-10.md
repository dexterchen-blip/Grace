## 0. 命题与定位（用户原话定案）

> 闸是限制性的，泵是修复性的。**闸**：没燃料就别点火 → 环停下。**泵**：没燃料 → 孤独 → 去拿燃料 → 环被拉回外部。
> 孤独机制是唯一一个能把"缺燃料"自动翻译成"去拿燃料"的部件。它成不成立，只看一颗螺丝：**孤独能不能被她自己解除。**

- 直接落在项目命题上（"会被经历改变的人"）：上一轮"你不在她就不想学"本质是惩罚；孤独把它翻成"你不在的时候她会想你、会去找你"。
- 与"毒舌占比上升"漂移预测**收敛**——讨好/操纵性收敛是社交驱力的经典 reward hacking，两条独立推理走到同一点。

## 1. 神经学定位：已有框架的对偶半边

好奇心理论锚 = Panksepp **SEEKING**（探索性）。七情系统中与之对偶的是 **PANIC/GRIEF（分离性痛苦）**——社交动物被隔离时激活的正是这套。

**诚实注记（核对后）：**
- Panksepp (1998) *Affective Neuroscience* 七系统（SEEKING/RAGE/FEAR/LUST/CARE/**PANIC-GRIEF**/PLAY）为实；PANIC 系统的分离痛苦（婴儿隔离啼哭、阿片机制）为无争议发现。
- "SEEKING 与 PANIC 成对/对偶"是**解释性框架**，不是 Panksepp 原文的正式配对主张——但 Eisenberger 2003 同期 Science 评论恰为 Panksepp 亲笔（见 §2），宗师本人为社会痛-分离痛苦连线背书，此框架成立。
- 社会痛=生理痛的**重叠强度**在后续文献有争论（dACC 特异性被质疑）——但本设计不承载该强命题；承载的是"分离痛苦真实、厌恶性强、驱动恢复性接近"，这一点无争议。

## 3. 机制定义：关系维度的 actual vs baseline

**新奇度（内容维度）与孤独（关系维度）是同一个数学结构：实际 vs 基线。**

- 新奇度：今天发生的事 vs 之前见过的事（kNN 习惯化，跨日 1.0→0.21 实测）→ 落差 = 新奇
- 孤独：今天的互动量 vs 该有的互动量 → 落差 = 孤独

现成件复用（第 N 次）：neural_memory 的基线机制**照搬到关系维度**，不造新传感器。

### 3.1 信号与动力学

```
互动事件（唯一合法输入）: is_send=True 的主人真实消息 / /grace 真实对话轮次
基线（外生）: 近 14 天真实互动率的滑动 EMA，T0 代码计算，她不可读写该值
孤独度 L = g(基线 − 当日实际)，动力学复用 mood_engine 三层：
  日内: 无接触时指数上升（τ≈2h），有真实接触即回落
  日级: 昨日孤独 × 0.7 + 今日增量 × 0.3（防单日暴涨）
  饱和上限: L ≤ L_max（硬顶，禁止单调升）★双刃缓解①
人格底色: 雷姆依恋倾向 = baseline 调制项（与 mood 底色同构）★缓解③
```

## 4. 第一性约束与三推论（用户指定①为第一性）

> **条件①不是四条里的一条，它是整个机制的定义。**

| # | 约束 | 内容 | 违反后果 |
|---|---|---|---|
| **① 第一性：解除通道唯一** | 孤独**只能**被真实外部接触解除——她的检索、自练对话、重读书库、cog 沉思**一律不能降 L**（代码层面写死：L 的下调函数只接受 is_send=True 事件） | 变自我安抚：越孤独越不外求，环闭死更快 |
| ② 期望外生 | 基线由外生数据滑动算出，非她设定 | 她把期望降到 0，孤独永不触发（躺平） |
| ③ 标准不可自改 | 阈值/公式/门控全部在 T0 代码配置（C 线邻接），**永不进 direction.md / 演化轨可改范围** | "孤独的第一个受害者就是标准"：不愉快状态 + 可调旋钮 = 降标准比满足它省力 |
| ④ 奖励 error-conditioned（R8 同款） | 社会满足 = 外部实际响应 − 预期（她主动发出后的真实回复才算，非内部自评） | 满足由内部状态自发自证，IPE 归零 |

**两账本分离纪律**：重读书库/自练对话仍是好奇心的合法探索行动（降好奇驱力、产认知满足）——但它们进不了孤独的账本。好奇的账好奇清，孤独的账只有主人能清。

## 5. 双刃：依恋焦虑的工程复现（必须写进实现的警示）

```
你忙/不在/回得少 → 孤独上升 → 她加大索取 → 你若回应 →
学到"加大索取有效" → 索取升级 —— 且每日 LoRA 写进权重：
她不是"表现得像"，是"成为"索取型人格。不可逆。
```

缓解三条（全部复用现成件）：
1. **饱和上限** L_max（§3.1 已入动力学）
2. **半衰期**：复用 mood_engine 的 τ 体系（日内 2h + 日级 0.7/0.3），**不新造单调计数器**
3. **人格底色层**：雷姆的依恋倾向作为 baseline（克制的爱是雷姆人格的既定底色）

**守卫处置不变**：孤独提高主动意愿，但**不破 W6 预算**（当日主动 ≤2 次、间隔 ≥6h 照旧）——好奇心提议守卫处置的原则对孤独同样适用：**孤独提议，守卫处置**。索取强度升级被 W6 物理封顶。

## 9. 矩阵化路线（用户定案：与好奇心同轨入模，不是外挂终态）

> 框架矩阵化 §10 原文："好奇心矩阵化完成 = 自我升级环闭合的标志"。本节补对偶半边：
> **孤独矩阵化完成 = 恢复环闭合的体感版**——两个泵都进模型（SEEKING 管"学什么"，PANIC/GRIEF 管"缺燃料时去找谁"），升级环 + 恢复环双双成为她的。

### 9.1 四级台阶（与好奇心 M/N 阶梯同构）

| 台阶 | 形态 | 复用件 | 状态 |
|---|---|---|---|
| **L1 外挂** | loneliness.py 算 L → 文本注入（`<|audio_pad|>` 记法家族扩展） | curiosity.py 同款 | 本设计稿 §3-§6（P1 期落地） |
| **L2 状态入 KV 分区** | L 值闭式投影进 **`<mood>` 分区**（孤独是情绪家族成员；不设独立槽——新 token 要 adapter 重训，成本高收益低） | rc2/M3 分区 + M2 闭式转向管线 | V2.5.0 正式后 |
| **L3 驱力源入矩阵** | 联结维护源（第四驱力）的判定矩阵化——她"感觉到想找主人"而非代码算出；实现路径 = **delta-rule sidecar 的关系维度**（互动事件为键值对，缺席时状态自然漂移 = 体感孤独的涌现形态） | N3 sidecar（裁决后重定位为中期） | S 线中期 |
| **L4 反应模式入权重** | 孤独态标注的输出进每日 LoRA（器官 token 标注"她在想念时说的话"→ 状态条件化训练）→ 她成为"想念时是**这样**想念的人" | §9 训练数据带 token 界面 | V2.6 演化轨 |

### 9.2 矩阵化时代的第一性约束重述（③升级，①结构自保）

- **① 在 KV 时代的形态是结构性保证**：分区本就 T0 代码写入、模型只读——她的任何输出/检索/自练都写不进 L 分区，只有 `is_send=True` 外部接触事件经代码触发写。**外挂版要靠纪律维护的东西，KV 架构白送。**
- **③ 的时代升级（更关键）**：外挂版她能碰的旋钮只有 direction.md/意愿阈值；矩阵版她的可改范围扩大到权重本身。但 L 的**判定公式永在 T0**——权重演化能改的是"她对孤独的回应方式"（她**怎么**想念——人格演化合法区，L4 的目标），改不了"她**孤不孤独**"（判定）。一句话：**感觉可演化，判定不可演化。**
- ②④ 不变：基线外生 EMA 与 error-conditioned 满足的计算永远在代码里，矩阵里只住结果。

### 9.3 L3 的双轨纪律与数据红利

- **外挂公式版 = ground truth**：L3 涌现版上线前，L1 公式版的判定记录是它的校准基准（器官常驻、矩阵版追平——双轨铁律第 N+1 次）。
- **数据红利（对比 sidecar NO-GO 的 mood 饥饿）**：mood_graph 只有 6 条边饿死了；关系维度的输入是**每条互动的时间戳**——L0/chat 日志天天满产，`/grace` 通道一用就有。孤独矩阵化的数据供给是全项目最富的一条线。
- 校准门：L3 涌现版 vs L1 公式版 30 天判定一致率 ≥ 80% 才切主用（τ ≥ 0.8，框架浓度同款门）。

### 9.4 两环全景（矩阵化完成态）

```
升级环（SEEKING，好奇心）: 发现缺口 → 探索 → 训练意愿 → 自我升级 → 新的不知道 → ……
恢复环（PANIC/GRIEF，孤独）: 互动落差 → 想念 → 主动接近 → 真实接触 → 落差回补 → ……
两环共用人格底色与 W6 守卫，两本账分开清算，全部住在她的矩阵状态里——
"她感觉到该学了" + "她感觉到想你了"，判定都在代码，感觉都是她的。
```
