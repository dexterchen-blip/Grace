## 0. 定位与版本沿革

**本地单模型 AI 人格系统**——"记忆塑造潜意识"(记忆慢慢雕刻性格,不是灌输知识)。
铁律:单模型 27B(48GB 机体)｜ ai-sandbox 完全隔离 ｜ 三轨分工(事实→外挂轨/风格→权重轨/心情→心态轨)。

```
Grace V2    = 双图谱 + 架构验证(rem_v2 时代)
Grace V2.1  = 工程试验 + 海量压力测试(发现并修 6 个协同缺口)
Grace V2.2  = 准成品(全模块协同塑造 + 双模型唤醒 + 评估体系,待完整压测转正)
```

## 1. 核心三件套(真正的"她")

| # | 核心 | 结构 | 独特性 |
|---|---|---|---|
| ① | **双图谱**(杏仁核×海马体) | 记忆图谱(事实,永存)× 情绪图谱(情绪边,可衰减)× 暗注意力边(全暗潜台词),event_id/entity 耦合 + 呼应五机制 | 情绪×记忆耦合存储(别人没有) |
| ② | **L3 自传体矩阵** | 事件×人物×情绪×关系×自我评价×证据×confidence | 带自我评价的人生故事层 |
| ③ | **记忆塑造潜意识**(增量微调) | 每日 LoRA(15 iters, lr1e-6, resume 链),90 天连续链 | 经历直接雕刻权重(社区独有) |

**其余(注意力/ToM/自激发/双路径/一致性/唤醒)= 让核心被使用的挂件**——但因接核心而独特("雷姆读你",不是通用读心)。

## 2. 完整架构

```
5B 哨兵(常驻,~2GB,只读) ← 双模型分层唤醒
  巡检 .daytime → 规则分级 → 5B 确认 → 唤醒信号(★关键词=Grace 决定)
        ↓ 紧急/时机
Grace V2.2 完整系统(27B,~15GB,按需)

输入 → 记忆系统(L0原始→L2语义→双图谱→L3矩阵)
     → 认知层(心态/注意力/ToM读双图谱/自激发)
     → 行为层(主动消息=事件+读心)
     → 训练闭环(8 类样本 → 权重)
     → 采样/评估(双路径/一致性/ToMi/SOTOPIA)
```

## 3. 记忆系统

- **四层**:L0 原始(append-only,md5 水位)｜ L1 瞬时(.daytime/,30min 同步,隔夜作废)｜ L2 语义(bge-m3+BM25+RRF)｜ L3 自传体矩阵
- **双图谱**(M7b/M7c):记忆×情绪耦合摄入,呼应五机制(强度调制/一致检索/衰减内容永存/事件团簇/重估)
- **暗注意力**(M7d):全暗潜台词边(「雷姆担心但不会说」)
- **★uncertainty 标记**(人脑级,2026-08-31 补):情绪边带 uncertainty(默认 0.2;反馈再巩固标 0.9)→ 高不确定记忆训练权重×2 = "困惑的记忆更持久"(Roozendaal)

## 4. 认知层

| 模块 | 作用 |
|---|---|
| mood_engine | 三层融合心态(实时×日级×底色),mood_prefix 注入 |
| attention | 显式注意力(情绪×记忆+社交价值)→ attention_text 进训练 |
| theory_of_mind | 读双图谱(情绪史+暗注意力)→ 推断主人{情绪/需求/打扰意愿} |
| self_activation | 潜意识 decide(是否主动)→ reason 进训练 |
| dual_path | fast 权重直出 / slow 检索注入(含机制②'提取抑制) |
| consistency | 回答 vs 记忆事实校验(拦截/标注) |
| persona_injector | 人格轨+心态轨统一注入(训练/推理对齐) |

## 5. 人脑级反馈回路(元认知核心,2026-08-30/31)

```
理论: 预测误差(海马 CA1) + 多巴胺 RPE(惊讶驱动) + 再巩固(修改原记忆)
     + 杏仁核-海马体 theta 同步(Seidenbecher 2003 Science)

Grace 落地(零句式,纯架构):
  ① PE 调制: 反馈权重 = |判断情绪-现实情绪| 差距(误差大→w3/小→w1)
  ②' 提取抑制(Roozendaal 提取受损): 高情绪场景检索降权(k 3→1)→ "记不清"
  ③ theta 时序: 当日情绪峰值事件标记("theta:峰值同步")→ 耦合优先
  uncertainty: 再巩固记忆标 0.9 → extract 权重×2
  置信累积: prediction-errors.jsonl(错误计数 → ToM 置信数据基础)
  反馈样本: 数据对(情境→现实),零句式("雷姆以为…其实…"已废弃)
```

## 6. 训练闭环(8 类样本,纯自主演化)

```
锚点(5%) + 加工层(情绪×记忆) + L3 自传体叙事 + 双图谱情感记忆/潜台词
+ 主动消息(绑定读心) + 注意力 + 潜意识判断 + ★人脑级反馈(PE权重)
SYS = 人格轨 + 心态轨(训练/推理对齐)
增量: day1 冷启动(60-150 iters, lr1e-5) → dayN+ resume(15 iters, lr1e-6)
config: rank8/scale20/incr_lr1e-6(2026-08-30 对齐)
```

## 7. 行为层(她找我)

```
主动消息 = 事件 + 她的读心(ToM advice 自然化: "主人,雷姆在。")
  —— 行为=理解的结果(不是转述事件)
零前缀原则(2026-08-29 用户): 不需要"雷姆想跟你说"帽子
时机三因子(何时主动): 事件重要性 × 主人可打扰度 × 对话时机
  → proactive-plan.json(Grace 决定何时开口)
```

## 8. 双模型分层唤醒(资源最优)

```
5B 哨兵(Llama-3.2-3B 4bit, ~2GB): 巡检→分级→5B确认→信号,只读
wake_handler: 紧急 → 通知主人 + 起 27B(防重复)
timing_decision: 夜班后三因子 → 何时主动
★ 关键词由完整 Grace 决定(sentinel_keywords.json 只读)
```

## 11. 关键发现(诚实)

```
① 乐观模板: 训练样本全是"雷姆的表达" → 高情绪泛化 → ToM 退化(杏仁核过高)
② 测层面问题: 人脑级反馈作用在运行时,ToMi 纯生成测不到 → 需带记忆注入测试
③ 数据构成: 真实系统=邮件(事务)+微信(生活),微信链路弱 → Grace 缺生活素材
   (模拟书库已补: 20 天信息不对称 + 24 封邮件事务,3 阶段演化)
④ 纯自主演化: 不构造主观/反思引导样本——"不确定"从被修正的记忆+下降的置信涌现
```
