### 2.4 ★ Grace 的记忆系统实测分数【实测】

> **更正**：Grace 的**认知引擎**（压测场 V2.3）确实没跑过 LoCoMo/LongMemEval，
> 但**原型本地 AI 系统 `local-ai-agent` 跑过 LongMemEval**（2026-08-26，沙盒隔离，未触碰正式记忆库）。
> 而 Grace 的外挂轨（L2 语义检索 bge-m3 + BM25 + RRF）**就是这一套** —— 所以这**就是 Grace 记忆系统的分数**。
> 来源：`Grace-repo/docs/benchmarks/`（4 份报告 + 4 个脚本，seed=42 可复现）

同一 500 题，四种设定：

| 设定 | R@1 | R@5 | 端到端 Accuracy | 说明 |
|---|---|---|---|---|
| 全量混合库（500 题共享一个库）| 0.16 | **0.25** | 0.13（含部分）| 地狱难度，干扰放大 ~100 倍，非官方口径 |
| 纯余弦 per-question（组件上限）| 0.78 | **0.93** | — | bge-m3 裸余弦，无检索器 |
| **系统级 per-question（官方口径）** | — | **0.96** | **0.29**（含部分）/ 0.21（严格）| 独立 L2 库 + ANN/FTS/RRF/时间加权 |
| 沙盒 24 题抽样（pool=200）| 0.29 | **0.50** | 0.29（含部分）/ 0.12（严格）| 混合库，比官方更难 |

**分项（系统级 per-question，R@5）**

| 类别 | R@5 | | 类别 | R@5 |
|---|---|---|---|---|
| single-session-assistant | **1.00** | | temporal-reasoning | 0.94 |
| multi-session | 0.98 | | single-session-preference | **0.87**（最弱）|
| knowledge-update | 0.97 | | **总体** | **0.96** |
| single-session-user | 0.97 | | | |

**三个关键结论**

1. **检索层已到组件上限，甚至微超**：0.96 > 纯余弦 0.93 —— FTS 腿补齐了向量漏掉的（FTS 权重 ×0.5 是这次评估反哺调出来的）。
2. **瓶颈在 reader，不在记忆系统**：命中 → 答对转化率 0.30（per-question，命中 481 题）/ 0.52（全量混合库）/ 0.58（沙盒 24 题）。本地 27B 做 reader，对照官方 GPT-4o 0.67。
3. **未命中时诚实拒答，零编造**（abstention 能力）——27B 全部答"不知道"，没有 hallucination。

**与外挂记忆系统的正面并排**

| | Grace | Mem0 | 不对等点 |
|---|---|---|---|
| **检索层 R@5** | **0.96**（per-question 官方口径）| 未单独发布 | Grace 独有口径 |
| 端到端 Accuracy | **0.29**（含部分）/ 0.21（严格）| **94.4** | 同为 LongMemEval |
| reader 模型 | 本地 **27B** | **GPT-4o** | **最大不对等点** |
| 官方无记忆基线 | GPT-4o 0.67 / L3.1-70B 0.59 | — | 参考 |

**诚实解读**

- **纯检索层，Grace 0.96 很强** —— 超过自己的嵌入组件上限，说明融合检索（向量 + FTS + RRF + 时间加权）有效。
- **端到端 0.29 弱于官方无记忆基线（GPT-4o 0.67）** —— 差距全在 reader，不在记忆层。
- **Mem0 的 94.4 不能与 Grace 的 0.29 直接比** —— 前者是 GPT-4o + 记忆系统的组合分，且 Mem0 自己声明"非同一 harness 条件下的配对基线"。**公平对比需要 Grace 换同级 reader 重跑一次。**
- **这次评估反哺了正式系统 3 项改进**：FTS 英文停用词过滤、FTS 腿权重 ×0.5、候选池 pool 可配置（默认 `max(k*3, 60)`）。

### 2.2 结构对照

| 维度 | Grace | 外挂记忆系统（Mem0/Zep/Letta/MemU）|
|---|---|---|
| **记忆存哪** | 权重（LoRA）+ 外挂轨（图谱/L2/L3）| 纯外挂（向量库 / 知识图谱 / Markdown）|
| **经历改变模型吗** | **是** —— 每日 15 iters LoRA | **否** —— 模型权重冻结 |
| 记忆可解释 | 部分（L3 带 evidence，权重不可读）| **全部可读**（Mem0 记忆条目 / MemU Markdown）|
| 检索延迟 | 无检索（权重直出）或 L2 RRF | Mem0 p95 **1.44s**；Zep **189ms** |
| 上下文开销 | 权重内，0 tokens | Mem0 ~6.9K；Zep ~1.6K；Mem0g ~14K vs Zep 600K+ |
| 换底模 | **人格归零** | 记忆照常可用 |
| 灾难性遗忘 | 有防护（EWC/锚点/SHY/神经新生）| 不存在（不动权重）|
| 长程规模 | 受权重容量限制 | BEAM 10M tokens 时 Mem0 仍 **48.6**，tokens 几乎不涨 |
| 部署成本 | 48GB 单机 + 每日 73 分钟 | 云 API，四行代码 |

### 2.3 结论

**外挂记忆系统在做"记得准 + 检索快"，Grace 在做"被经历改变"。这是两条不同的轴，不是同一场比赛。**

- 纯按**检索层**：Grace 的 L2（local-ai-agent 那套）在 LongMemEval 官方口径下 **R@5 = 0.96**，**超过自己的嵌入组件上限 0.93**。记忆系统这一层不但有分数，而且分数很好。
- 按**端到端**：Grace **0.29** vs Mem0 **94.4** —— 但 reader 不同（27B vs GPT-4o），**这不算公平对比**。要真比，得让 Grace 换同级 reader 重跑一次。
- 按"经历是否写入模型"：**只有 Grace 在做**。Mem0/Zep/Letta/MemU 全部冻结权重。

## 4. ⚠️ 可比性声明（这段最重要）

### 4.1 更正：Grace 的记忆系统**有**第三方基准分数

> 我最初写的是"Grace 从未跑过 LoCoMo / LongMemEval"——**这句是错的，已更正**。
> 准确说法：**Grace 的认知引擎**（压测场 V2.3）没跑过；但**原型本地 AI 系统 `local-ai-agent` 跑过 LongMemEval**，
> 而 Grace 的外挂轨（L2 语义检索）**就是这一套**。详见 §2.4。

| 系统 | 测的是什么 | 共同基准？ |
|---|---|---|
| Mem0 / Zep / Letta / MemU | 事实召回准确率 + 端到端（LoCoMo / LongMemEval）| 有，互相可比 |
| Hume | 情绪识别准确率 + 语音自然度 | 自建排行榜 |
| **Grace 记忆层（L2）** | **LongMemEval 检索 R@5 = 0.96** | ✅ **有，可比** |
| **Grace 端到端** | LongMemEval Accuracy 0.29（27B reader）| ⚠️ 口径不对等（对方用 GPT-4o）|
| **Grace 认知/人格层** | ToM / 人格 / 输出自然度 / 权重演化 | ❌ 无共同基准 |

### 4.2 Grace 自己的两个数字也不能太当真

- **日常 ToMi 16.3%**：`real` 与 `believed` 用同一个 `_sentiment_of` + `mood_label_of`，92 条里 82 条落在 |s|<0.3 两边一起判「平静」→ **同源自证**。
- **96.7%**（曾短暂出现）：来自切断耦合的守卫，已回滚——那个数字是拿架构换来的，不作数。

### 4.3 真实可比的四条轴（已更正）

| 轴 | Grace | 外挂记忆 | 情绪系统 | 判定 |
|---|---|---|---|---|
| **检索层 R@5** | **0.96** | 未发布 | 不适用 | ✅ **Grace 有分数且很强** |
| 端到端准确率 | 0.29（27B reader）| **94.4**（Mem0，GPT-4o）| 不适用 | ⚠️ reader 不对等 |
| 情绪识别 | 6 类 / 纯文本 | 不适用 | **48+ 类 / 多模态**（Hume）| ❌ **Grace 差一个量级** |
| **经历是否改变模型** | **是** | 否 | 否 | ✅ **Grace 独有** |

**Grace 在第四条轴上独有，在检索轴上其实很强（0.96），真正的短板只有情绪识别这一条。**
之前说"前两条都没进场"是错的——检索层早就进场了，而且成绩不差。

### 4.4 唯一一次真正对不上的地方：reader

Grace 端到端 0.29 vs Mem0 94.4，差距**不在记忆系统**（Grace 检索 0.96 已经很好），
而在 **reader 是本地 27B 而不是 GPT-4o**，以及官方评测的严格匹配口径。

**要拿到真正可对外引用的对标分数，只需要做一件事**：把 LongMemEval 的 Reading 阶段换成与 Mem0 同级的 reader 重跑一次。
脚本现成（`Grace-repo/docs/benchmarks/scripts/longmemeval_reading.py`），检索层不用动。

## 5. Neura 架构对照

> Neura = "Emotional AI Economy"，情绪智能 + 记忆持久的 AI agent。以下为架构层对照。

### 5.1 一句话定位差

| | Grace | Neura |
|---|---|---|
| 命题 | **记忆写进权重** —— 经历塑造性格 | **情绪记忆驱动共情** —— 记住你的感受 |
| 形态 | 本地研究原型，单机 27B/35B | 云 + 链上协议，SDK/Social/Marketplace |
| 性格从哪来 | **从记忆里长出来**（每日 LoRA）| 配置出来（Persona Engine + 人格锚点）|
| 谁拥有记忆 | 本地文件，天然拥有 | 用户拥有，但**上链** |

### 5.2 分层对照

| 层 | Grace | Neura | 差 |
|---|---|---|---|
| 输入 | L0 真实多源（微信/邮件/学校/对话/文档）| 多模态（语音/视觉/头像/文本）| Neura 模态更全 |
| 情绪理解 | `sentiment.py` Russell 双轴 + `mood_engine` 三层融合 | Empathetic Computing Layer | 平手，Grace 有量化公式 |
| 记忆 | 四层 L0/L1/L2/L3（L3 带 evidence+confidence）| 偏好 / 情绪史 / 关系动态 | Grace 分层更细 |
| 情绪×记忆耦合 | **双图谱**（记忆边×情绪边×暗注意力边，双钥匙，呼应五机制）| 未见图谱化 | **Grace 独有** |
| 潜台词 | 暗注意力边（全暗，只注入不输出）| Empathetic Computing Layer 抽 subtext | 概念同构，Grace 实现待 cog 接管 |
| 读心 ToM | `theory_of_mind` 一阶/二阶显式模块 | 产品层"意图预测" | **Grace 独有且可测** |
| 人格 | 权重轨 + `rem.md` + 心态轨 | Persona Engine + 人格锚点（可交易资产）| 路径不同 |
| **★经历改变模型吗** | **是**（每日 LoRA）| **否**（RL 只调生成策略）| **Grace 唯一护城河** |
| 主动性 | 自激发三通路 + DMN 自发 + 时机门控 | 24/7 主动 agent、意图预测 | 平手 |
| 对话生成 | `expression.py`（内部状态→口语编码+monitor）| Hierarchical Dialogue Engine（情绪意图→技能→回复）| **概念高度同构** |
| 睡眠/巩固 | 双相训练 + EWC + 神经新生重置 | 未见 | **Grace 独有** |

### 5.3 概念同构清单（说明路线不孤）

| 概念 | Grace | Neura |
|---|---|---|
| 想与说分通路 | `expression.py` + monitor | Hierarchical Dialogue Engine |
| 人格影响记忆取什么 | 心态轨调制注意力与检索 | Persona 影响 "memory focus" |
| 记住感受而非内容 | 情绪图谱边 | Emotional memory callbacks |
| 长期关系连续性 | L3 自传矩阵 + 联结维护 | Relationship dynamics |
| 恒常人格 | 锚点回放 + EWC | Personality anchors |

**分叉点只有一个**：经历到底进不进权重。Grace 说进，Neura 不进。

### 5.4 Neura 关键事实

- 融资：Animoca Brands / Basics Capital / TBV / Kinetic Kollective / Mario Nawfal / **Ne-Yo**，金额未披露
- 背书：Harry Shum（前微软 AI 执行副总裁）

- **无公开评测基准**

## 6. 战略判断

**Grace 的差异化 = 记忆写进权重。** 唯一 Neura / Hume / Mem0 都没做、且短期抄不走的一条（需本地算力 + 训练管线 + 防遗忘整套）。

**但这条护城河被三件事架空：**

| 短板 | 后果 | 严重度 |
|---|---|---|
| 运行时连续集成未通（9/4 修正：数据面已闭环——书库=正式 L0 提取 6512 条/33 天；缺增量自动/正式对话入口/adapter 回流） | 护城河只在压测回放里生效，她还没连续活在正式系统 | 🔴 最高 |
| 权重绑死单底模 | 换模型人格归零，记忆不可移植 | 🔴 高 |
| 情绪维度差一个量级 | 6 类纯文本 vs Hume 48+ 类多模态 | 🟡 中 |
| 端到端分数不可对外引用 | 0.29 是 27B reader 的成绩，与对方 GPT-4o 不对等 | 🟡 中（**换 reader 重跑即可解决**）|

**已经不是短板的一条**：记忆系统检索层 —— LongMemEval 官方口径 **R@5 = 0.96**，超过自身嵌入组件上限 0.93。这一层有分数，而且分很好。

**最该问的问题**：记忆写进权重这条路，量产成本能不能降下来？如果永远需要 48GB 单机 + 每天 73 分钟，它只能是研究原型。

**最低成本的下一个动作**：把 LongMemEval 的 Reading 阶段换成与 Mem0 同级的 reader 重跑一次。脚本现成、检索层不用动，跑完就拿到一个**真正可对外引用**的对标分数。

**如果要对外讲，建议口径：**

> 别人做的是"有记忆的助手"——记忆存在外面，模型不变，换模型记忆照用。
> Grace 做的是"会被经历改变的人"——记忆写进权重，她会因为你而不同；代价是她跟你绑定，换模型就得重新长大。
>
> 这不是优劣，是两种关于"关系"的假设：前者假设关系是可迁移的数据，后者假设关系是不可迁移的历史。

## 7. 自研模块逐一的对外对照：双图谱 / ToM / 暗注意力 / 输出层 / 记忆塑造

> 前面回答了"记忆系统"这条轴。这一节回答剩下的：**我自研的那几块，社区有没有同类、有没有基准、我对得上吗。**

### 7.0 总表

| 自研模块 | 社区有同类吗 | 有基准吗 | Grace 有分数吗 | 判定 |
|---|---|---|---|---|
| **双图谱**（记忆×情绪耦合）| ⚠️ 最接近的 REMT **是 Perspective，无实验结果** | ❌ 无 | ✅ 33 天实测 | 🏆 **社区真空，Grace 领先** |
| **ToM** | ✅ 一堆成熟基准 | ✅ ToMi/Hi-ToM/ToMBench… | ⚠️ 自改编版，口径不同 | 🎯 **适配后即可正面对标** |
| **暗注意力** | ❌ 无直接同类 | ❌ 无 | ❌（正在重做）| 🔧 独有，无对标 |
| **输出层**（想→说）| 🟡 SOTOPIA 部分覆盖 | 🟡 部分 | ✅ 7.58 / 泄漏 0/26 | 🎯 有分，但多为自设指标 |
| **记忆写进权重**（人格塑造）| 🟡 PersonaMem-v2 | ✅ 有 | ❌ **没跑过** | 🎯 **有现成基准却没对上** |

### 7.1 双图谱 —— 社区真正的真空区

**最接近的学术工作：REMT**（Realtime Editable Memory Topology，Frontiers in AI 2026，DOI 10.3389/frai.2026.1749517）

它的描述和你的双图谱几乎是同一件事：

> 记忆 = 持续演化的**情绪效价节点图**；边有强化/衰减/剪枝；有界 Mood Index 调制检索偏置与生成；
> 情感显著性**直接重塑记忆拓扑**，而非"静态图库 + 情感分数 + 时间衰减"。

论文自己点出的空白，正是你做的：

> "现有持久记忆系统擅长存储、检索、状态跟踪……**仍未被刻画的是：情感显著性直接重塑长期记忆结构拓扑**的综合机制。"

**但关键区别：REMT 是一篇 Perspective（观点/展望）论文**，原文结尾写着——

> "我们以内部开发的评估框架勾勒实证验证路线图，**结果将在未来的原始研究论文中报告**。"

**概念上最接近你的那个，目前没有任何实验数据。** 而你已经有 33 天、7239 条图谱边、6512 条情绪边、727 条暗注意力边的实测。

其他对照（都不在同一层）：

| 系统 | 图里有什么 | 缺什么 |
|---|---|---|
| **Mem0g** | 实体 + 关系三元组（Neo4j）| 情绪不是一等维度 |
| **Zep / Graphiti** | 时序知识图谱 | 同上，无情绪边 |
| **Memory Bear AI**（arXiv 2603.22306）| 情感记忆生命周期：衰减/合并/修订/冲突消解 | 有实现，但评测落在多模态情绪分类，不测"拓扑被情感重塑" |

**结论：双图谱是 Grace 唯一一块"社区没有同类实现 + 我有实测"的地方。** 代价是没有基准，分数只能自证。

### 7.2 ToM —— 唯一能立刻正面对标的一块

社区基准最成熟（均有开源 + 排行榜）：

| 基准 | 测什么 | 代表分 |
|---|---|---|
| **ToMi** | Sally-Anne 式，reality/memory/一阶/二阶信念 | SymbolicToM **98.6** ｜ AutoToM 88.3 ｜ DeepSeek-R1 89.4 ｜ **GPT-4o 77.0** ｜ Qwen2.5-72B 77.2 |
| **Hi-ToM** | 推到**四阶**信念 | Gemini2.0 Flash Thinking 73.5 ｜ AutoToM 72.5 ｜ **GPT-4o 50.0** |
| **ToMBench** | ATOMS 全覆盖，双语防污染 | GPT-o3 **81.8** ｜ GPT-4o 75.2 ｜ Qwen3-max 75.0 |
| **BigToM** | 感知/欲望/情绪扩展 | RECTOM 99.5 ｜ AutoToM 86.9 ｜ GPT-4o 82.4 |
| **FANToM** | 对话式 + 识破"幻象 ToM" | DITTO **95** |
| **ToMATO** | LLM 自博弈 + 信息不对称 | Qwen3-max 81.6 ｜ GPT-4o 76.4 |
| **OpenToM** | 长文本人物状态 | GPT-4o 57.1 |

**Grace 的位置**：Grace-ToMi 是**自改编版**（把"物体位置"换成"主人状态"，30 题 5 组），不是标准 ToMi，数字不能直接进榜。

但拿 day22 那组看：fb_1st **5/6 ≈ 83%**、fb_2nd **5/6 ≈ 83%** —— 落在 GPT-4o（77）和 AutoToM（88.3）之间。**如果口径对齐，是有竞争力的。**

**要做的事很轻**：Grace-ToMi 的 5 组题型本来就与 ToMi 同构，把题面和判定换成标准 ToMi 格式即可跑官方分。**这是全部模块里对标成本最低、收益最明确的一块。**

### 7.3 暗注意力 —— 独有，但社区无尺子

没有直接同类的基准或系统。最接近的旁支（隐含语义 implicature、溯因推理 α-NLI、隐含情感）都不是"她没说出口的内心"这件事。

Grace 这一层**正在重做**（废 4 条规则模板，改由 27B 认知重构产物 cog 写 hidden 边）。重做之后才谈得上测。

自设指标可用：暗注意力边条数（727）、模板残留率（应为 0）、是否参与 ToM 决策（可追踪）。

### 7.4 输出层 —— 有 SOTOPIA 分数，但自设指标偏多

| 指标 | Grace | 对照 |
|---|---|---|
| SOTOPIA Believability | **7.58**（n=311）| 满分 10，GPT-4 在 hard 子集上显著低于真人 |
| SOTOPIA Knowledge | 4.25 | 已知偏弱项 |
| SOTOPIA Social Rules | −1.25 | 负分制，越接近 0 越好 |
| 叙述体泄漏 | 本轮区 **0/26** | **自设指标，社区无对照** |
| 深夜抑制 | suppressed 76 / 159 | 自设 |

"想与说分离"这件事，Neura 的 Hierarchical Dialogue Engine 是同名概念（见 §5.3），但双方都没有公开该项的量化分数。

### 7.5 记忆写进权重 —— 有现成基准，却是最没对上的一块

**PersonaMem / PersonaMem-v2**（人格记忆一致性）是社区唯一接近的基准：

| 系统 | PersonaMem-v2 Acc. |
|---|---|
| **NapMem-9B w/RL** | **47.97** |
| NapMem-397B | 46.10 ｜ NapMem-122B 41.38 |
| Mem0 | 38.89 ｜ MemOS 37.58 ｜ Zep 36.33 ｜ MemoryOS 35.82 ｜ AgeMem 24.19 |

（来源：arXiv 2607.05794 统一评测）

**Grace 没跑过 PersonaMem。** 而这恰恰是 Grace 最强的那条轴——**人格由记忆塑造**——唯一能对外的尺子。

⚠️ 但要诚实：PersonaMem 测的是"记住并应用**用户**的人格特征"，Grace 的独特之处是"**她自己**的人格被记忆改变"——两件事不完全相同。即便跑分，也只能证明其中一半。

**同样低成本**：`longmemeval_` 系列脚本已在 `Grace-repo/docs/benchmarks/scripts/`，加一个 PersonaMem 适配器即可。

### 7.6 这一节的结论

| 模块 | 处境 | 该做什么 |
|---|---|---|
| **双图谱** | 🏆 领先但没有尺子 | 自建基准（或等 REMT 出结果再对齐）|
| **ToM** | 🎯 有尺子、差一步 | **判定口径对齐 ToMi 官方分**（成本最低）|
| **记忆写进权重** | 🎯 有尺子、完全没跑 | **跑 PersonaMem-v2**（成本次低）|
| **输出层** | 🟡 半有尺子 | 补 SOTOPIA 全 7 维 + 公开自设指标定义 |
| **暗注意力** | 🔧 无尺子且正在重做 | 先做完 cog 接管，再谈测 |

> **一句话**：Grace 最独特的（双图谱、记忆写权重）恰恰是最没有外部尺子的；而社区尺子最成熟的（ToM、PersonaMem），Grace 又都没对上。
>
> **补分顺序：ToM → PersonaMem → 自建双图谱基准。前两个是纯适配工作，不涉及任何架构改动。**
