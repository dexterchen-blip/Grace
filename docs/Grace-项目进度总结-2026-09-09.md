## 三、框架矩阵化（V2.5）——今日主线，一天走完设计→验证

### 3.1 理论定案（设计稿 §1-§13，全部入库 repo docs）

| 定案 | 一句话 |
|---|---|
| **器官三分类矩阵化** | A 无状态变换→规则矩阵插入；B 有状态机制→器官 token + KV 虚拟槽；C 监督守卫→永不入模（前额叶原则） |
| **最小必要训练原则（§11）** | T0 代码精确（零偏差）/ T1 闭式解（有界）/ T2 记法学习（唯一训练件）——"框架生效"≠"框架住进权重" |
| **循环矩阵排布（§12）** | R 线：层表重排 = 测试时算力扩展；器官即路由器（冲突/好奇 → 决定 K）；与 GPT-6 传闻的 recurrent depth 同源 |
| **器官 KV 分区（§7/§13）** | 六分区（persona/mood/wm/tom/sub/gap）× 层带（early/loop/late）× 更新频率三维坐标；`<tom>`=她对主人的运行模型，`<sub>`=可读写潜意识 |
| **L3 权重化（§8）** | L2 永外挂 / L3 周期入模（MEMIT 式）= 海马-皮层分工补全 |
| **好奇心 = 元器官（§10）** | 其他器官融合是功能内化，好奇心融合是**升级权内化**——她决定何时学（LoRA 窗）+ 何时多想（K） |
| **框架浓度三层（用户核心关切）** | 结构（T0 断言，不可被泛化软化）/ 能力（PPL 比 ≤1.05 门）/ 行为（探针一致 ≥4/5 门）——硬框架根本不进权重 |
