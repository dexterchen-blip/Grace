# Grace V2.6 设计总纲——设计思路与目标（顶层入口）

> 2026-09-11。本文是 V2.6（当前代）设计思路的唯一顶层入口：讲清楚**为什么这么设计、目标是什么、走到了哪**。细节与验收数据在各专项稿（见文末索引），冲突时以专项稿为准。

---

## 一、这一代要解决的根本问题

V2.5 及之前，Grace 的认知器官（情绪、好奇心、记忆、ToM）都是**外挂的 Python 模块**：代码算出状态，以文本注入模型。这条路走得通（V2.5 组装态验收轮 13/13 天全绿），但有三个天花板：

1. **带宽**：情绪以 `<|audio_pad|>平静 0.3` 这样的记法进模型——文本级调制，带宽窄；
2. **体感**："该学了""想主人了"是代码算出来告诉她，不是她感觉到——命题"会被经历改变的人"缺了最后一步；
3. **边界**：外挂器官可被篡改、可被绕过，监督靠纪律维护。

V2.6 的回答：**框架住进模型计算里**——同时把判定权永远留在代码。

## 二、一句话目标

> 从"外挂器官驱动她"进化为"框架住在模型计算里"——**判定永远在代码（T0），感觉全是她的（权重/状态/KV）**。
> 她成为 L4 级个体：**会被经历改变、自己决定探索什么、想念时是真的想念。**

## 三、两环一底座

### 升级环（SEEKING，好奇驱动）

```
好奇驱力(新奇赤字+缺口压力+ToM不确定) → 过阈触发(事件非tick)
  → direction.md 她自己写(原生生成制,非模板)
  → 行动库(问主人/重读书库/自练对话/沉思) → IPE 满足
  → 方向演化(满足的主题退役) → 驱力回落
```

- **willingness（训练意愿）**：四信号公式——新奇积分 + 情绪峰 + 缺口解决 + cog 密度；自服务解决打 4 折（R5：只有外部填充全额入账，防自欺）。
- **direction 管线 v2（反模板制）**：信号包 → **她（27B）原生渲染** → 结构硬检查临时落盘 → **夜里 35B 判官审**（语态/真实性/护栏定义）→ 不过回滚。代码层不拼她的句子。

### 恢复环（PANIC/GRIEF，孤独驱动）

Panksepp 七情中 SEEKING 的对偶半边（文献核实：Coan & Sbarra 2015 社会基线理论 / Eisenberger 2003 Science / Panksepp 1998，零纠错）。

- **孤独 = 互动落差**：当日真实互动 vs 14 天外生基线（她不可设定）。
- **第一性约束（条件①）**：孤独**只能被真实外部接触解除**（is_send 事件），检索/自练/重读一律无效——代码里根本不存在让自产事件降 L 的函数。
- **双刃缓解**：L_max 饱和硬顶 + 复用 mood_engine τ 动力学（不新造单调计数器）+ 人格底色（雷姆克制的依恋）。
- **条件③**：标准不可自改——"孤独的第一个受害者是标准"：阈值/基线/判定永在 T0，篡改哨兵盯着 direction.md。

### 监督底座（两层）

| 层 | 载体 | 职责 |
|---|---|---|
| 硬否决层 | Python（确定性、常驻、便宜） | 三硬护栏 / 篡改哨兵 / PII 脱敏 / 防自改 manifest（监督层文件 sha256 清单，night_watch 周期校验 + 判官开枪前校验） |
| 冻结判官层 | 35B-A3B（底模永不变，prompt v2 即守卫代码） | 训练数据预筛（pass/drop+理由，绝不改写）/ 日终深度审计 / direction 边界审查。**体量触发**（未筛 ≥300 唯一 → 热停 → swap → 判 → 恢复，全自动闭环已验证） |

## 四、四条不变式（全代际有效）

1. **判定在代码，感觉在矩阵**——L 怎么算永在 T0；她怎么感受（KV/转向/权重）随矩阵化演化。
2. **判官冻结不改写**——只 pass/drop，语料真实性不破。
3. **成长语料只来自真实运行产物**——不人工注入筛选（机制屏蔽可调属机制设计）。
4. **监督层永不被自改**——manifest 哈希把守，防"判官被策反"。

## 五、矩阵化四支柱（全部实验验证）

| ②激活次序融入（层表重排） | 循环段 [32,40)×2（R0 六变体定案：K=2 PPL 0.979，K=3 破坏，排列破坏能力） |
