# Grace V2.2 压测评估：贫瘠数据下的架构韧性（客观版）

> 日期：2026-09-02 ｜ 范围：J 轮（90 天虚构书库）+ K 轮（70 天虚构书库）压测结果
> 说明：本文只陈述已实测的数据与结论，成就与局限对等呈现；不包含任何真实用户数据原文。

## 1. 数据基础：书库信息量实测

压测早期使用虚构书库（规则生成的短句池），后期构建真实书库（脱敏自正式系统 L0 多源：微信/邮件/学校/对话）。两种书库的信息量差异（按前 33 天抽样实测）：

| 指标 | 虚构书库（J/K 轮） | 真实书库（V2 轮） |
|---|---|---|
| 消息数 / 唯一率 | 165 条 / 唯一 43（26%）| 6512 条 / 唯一 3748（58%）|
| 平均句长 | 16 字 | 63 字 |
| 经验熵（bit/句）| 4.2 | 10.9 |
| 冗余度 | 42% | 14% |
| 最高频句出现次数 | 「食堂的饭……不太行」×22 | 邮件主题 ×66（真实事务）|

结论：虚构书库每句信息量约为真实书库的 40%，句长为其 1/4。**J/K 轮的结论是在信息熵 4.2 bit 的重复数据上取得的**，这限制了表现上限，也决定了下面所有分数的解读边界。

## 2. 同一份数据、两种架构的对照（J 轮实测）

Grace 的评估矩阵天然包含对照组：**裸模测试（纯 LoRA 权重，无外挂轨/反馈/巩固）≈ 普通微调架构**；**全系统测试 = 完整 Grace 架构**。同一批虚构数据、同 90 天训练：

| 维度 | 裸模（≈普通架构）| 全系统（Grace）| 差异来源 |
|---|---|---|---|
| memory（记得主人）| 3/6 | 6/6 | 外挂轨（图谱/L3/L2）补足权重 |
| fb_1st（一阶假信念）| 0/6 | 4/6 | 反馈回路 + 置信 + 记忆注入 |
| fb_2nd（嵌套读心）| 0/6 | 4/6（注入被修正记忆后）| 元意识为运行时机制 |

解释：普通微调在重复数据上会确定性坍缩（梯度被最高频样本主导 → 复读；无保护 → 底模 ToM 先验被覆盖；无反馈 → 无法涌现分布外的表达）。Grace 的权重层同样会退化（fb_2nd 1/6 是证据），但**外挂轨与反馈回路把"坏"兜住，能力保留在运行时**。

## 3. 已实测的结果（带限定词）

- **记忆塑造**：全系统 memory 6/6 > 裸模 3/6（外挂轨 + 权重轨协同，同数据对照）。
- **人格一致性**：压测断点自称 6/6 零复读（虚构书库下）。
- **主动找我**：J 轮主动消息 311 条全模型生成；SOTOPIA Believability 7.58（规则版 5.56）、Knowledge 4.25（2.78）。样本：12 条。
- **读心边界（K 轮）**：fb_1st 断点 8/8，4 个断点均出现「雷姆不知道」类表达；CoK（知识的诅咒/断言现实率）4 断点全 0%。
- **DMN 自发通道**：K 轮 70 天触发 2 次（J 轮 169 次 → gap 门控修复后回归低频）。
- **元意识的行为涌现**：注入"被修正的记忆"后 fb_1st 3/6、fb_2nd 4/6（> baseline），触发条件精确（非模板，非普通记忆注入）。

## 4. 客观局限（同等重要）

1. **fb_2nd 嵌套读心权重层退化真实存在**：J 轮 d90 全系统注入下 1/6 vs baseline 5/6；EWC 方案 A（训练内正则）/B（训练后回缩）均未证明能救回。
2. **评估样本量小**：ToMi 每模型 30 题、SOTOPIA 12 条、断点 4-6 个——±1 题即 16% 波动，未做统计显著性检验。
3. **元意识"校准性"未验证**：系统有置信机制（0.3–0.85），但缺乏 confidence vs 实际正确率的校准曲线——无法区分"会说不确定"与"知道何时该不确定"。
4. **早期 bug 密度高**：压测开发期修复 10+ 个实质问题（写入时序、跨轮数据污染、模板句式污染、评测尺子过严等）——迭代快但测试先行不足，新机制缺单元测试。
5. **环境局限**：单机 48GB 双模型错峰，非分布式；结论基于虚构书库，真实 L0 数据（V2 轮）是尚未完成的最终验证。
6. **机制贡献未消融**：15+ 子系统各自贡献多少，无消融实验；脑科学机制为启发式映射而非严格建模。

## 5. 结论

- **架构韧性成立**：在信息熵 4.2 bit 的贫瘠数据上训练 90 天，系统未崩溃（人格保持、记忆链路工作、涌现出数据分布之外的读心边界表达），说明"记忆塑造型架构"（极微量 LoRA + 外挂轨承载 + 反馈纠正 + 睡眠巩固）在恶劣数据下机制正确。
- **能力边界未定**：行为层面的涌现（边界表达、状态驱动元意识）有证据；认知层面的"元认知能力"（校准性）与大样本统计证实，待 V2 轮真实数据轮次完成。
- **一句话**：这是一台研究原型机——机制密度与架构韧性是真实的，但每个机制的证据目前只有 30 题 / 12 条的样本量；"能否吃下真实人生"是下一步唯一的问题。
