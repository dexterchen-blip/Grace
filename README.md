# Grace

**本地 AI 人格系统** —— 记忆 × 情绪 × 人格 × 自主性

Grace 是一个研究原型,探索「记忆 → 情绪 → 人格 → 自主性」的组合深度。核心思想:记忆不只是检索注入,而是**写进权重**(每日 LoRA 微调)——经历塑造性格,性格驱动行为,行为又产生新记忆(闭环)。

> 版本: **Grace V2.2 准成品**(2026-08-30,待完整压测验证转正)
> 版本沿革: **V2** 双图谱+架构验证 ｜ **V2.1** 工程试验+海量压力测试 ｜ **V2.2** 准成品 ｜ 前置: **Grace V2**(rem_v2 时代)

## 架构(一图)

```
5B 哨兵(常驻,轻,只读) ← 双模型分层唤醒: 爬虫巡检 → 突发分级 → 唤醒信号
   ↓ (紧急唤醒 / 夜班后时机决策)
输入层(书库/对话)
   ↓
记忆系统(四层)
  L0 原始 ｜ L1 瞬时 ｜ L2 语义(向量+BM25+RRF) ｜ L3 自传体叙事矩阵(带证据+幻觉守卫)
   ↓
双图谱(记忆 × 情绪耦合,杏仁核 × 海马体)
  记忆边(内容) ｜ 情绪边(半暗,可衰减) ｜ 暗注意力边(全暗,潜台词)
  耦合钥匙: event_id + entity ｜ 呼应五机制
   ↓
认知层
  心态轨(三层融合情绪) ｜ 显式注意力(情绪×记忆+社交价值)
  暗注意力(潜台词推导) ｜ 自激发(潜意识,无触发词) ｜ ToM 心理理论(读懂主人)
   ↓
人格层(权重轨 · 记忆塑造人格)
  底模 27B ｜ LoRA rem_v5(16层+grad-checkpoint) ｜ fused-rem-v5(管线直载)
  训练(7 类样本,纯自主演化): 锚点 + 加工层 + L3 自传体叙事 + 双图谱情感记忆/潜台词
       + 主动消息(绑定读心) + 注意力 + 潜意识判断 → 每日增量微调(15 iters, lr1e-6, resume 链)
   ↓
自主性层(她找我)
  注意力 → ToM(判断是否打扰) → 自激发 → 主动消息(进训练)
```

## 关键特性

| 特性 | 说明 |
|---|---|
| **记忆塑造人格** | 记忆 → 每日 LoRA 微调 → 写进权重(社区独有) |
| **双模型分层唤醒** | 5B 哨兵常驻(爬虫巡检/突发分级/只读) → 唤醒完整系统;关键词由系统决定 |
| **双图谱耦合** | 记忆图谱 × 情绪图谱,event_id+entity 双钥匙,呼应五机制 |
| **暗注意力** | 高情绪事件 → 潜台词边(「{实体}让雷姆担心,但雷姆不会说」),注入决策不输出 |
| **ToM 心理理论** | 推断主人状态(情绪/需求/打扰意愿)→ 决定是否主动找主人 |
| **L3 自传体叙事矩阵** | 事件×人物×情绪×关系×自我评价,生成「我的故事」 |
| **幻觉抑制** | evidence+confidence 标注 + hallucination_guard(7/7 测试) |
| **她找我** | 90 天自主运行,主动消息进权重(她会主动关心主人) |
| **实时 LoRA** | `--train-every 1`(每日微调) |

## 快速开始

```bash
# 压力测试(90 天回放 + 每日微调 + 全系统集成)
python v2/stress/stress_engine.py --days 90 --train-every 10

# 实时 LoRA(每日微调)
python v2/stress/stress_engine.py --days 90 --train-every 1

# 耦合本地系统模拟(完全摄入 L0)
python v2/stress/stress_engine.py --days 90 --ingest-official

# 主动会话(她找我)
python grace_book/grace_proactive_v3.py --days 90

# 幻觉测试(真实数据)
python grace_book/grace_hallucination_test.py
```

> 配置:本地绝对路径已参数化,请按环境设置 `GRACE_STRESS_DIR` / `L0_RAW_DIR` 等。
