# Grace — 本地 AI 记忆代理系统

本地全离线 AI 记忆与自动化代理系统（macOS / Apple Silicon）。

**设计目标**：个人数据主权 —— 邮件、微信、学校信息、对话全部落本地，双模型错峰调度完成
「摄入 → 理解 → 记忆 → 自动提醒」闭环，不依赖任何云端 API。

> ⚠️ 本仓库为**脱敏发布版**：不含爬虫采集层代码与思路、个人数据、模型权重、密钥。
> 隐私边界（记忆库 L0-L3、exchange 数据、test-sandbox、models/、人脸特征、密钥清单）一律不在此仓库。

└──────────────┬──────────────────────────────┬──────────────┘
               ▼                              ▼
┌──────────────────────────┐   ┌──────────────────────────────┐
│  L-1 瞬时记忆             │   │  夜班流水线（night_pipeline）  │

│  30 分钟同步，隔夜即清     │   │  → 知识图谱 → 审校 → 提案      │

               ▼                              ▼
┌─────────────────────────────────────────────────────────────┐
│  L0 原始记忆（JSONL）→ L2 语义索引（sqlite-vec + FTS5）          │

└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  dashboard（本地 :3091）+ 密钥系统（Keychain vault）            │

## 四层记忆（核心思路）

| 层 | 载体 | 生命周期 | 说明 |
|---|---|---|---|
| **L-1 瞬时** | `exchange/.daytime/` | 30 分钟同步，隔夜清空 | 白天对话触发的抓取临时文件；永不进正式记忆 |
| **L0 原始** | `memory/L0_raw/*.jsonl` | 长期 | 摄入的原始事实（唯一写入方 = 夜班） |
| **L2 语义** | `memory/L2_semantic/l2.db` | 长期 | 向量（bge-m3）+ BM25 双路索引，RRF 融合；知识图谱表 |
| **L3 核心** | `memory/L3_core/core.md` | 长期（git 版本化） | 事实/待办/规则/偏好，35B 巩固写入，27B 审校修正 |


## 双模型错峰铁律

- **白天 27B**（Qwen3.8-27B-4bit，MLX）：常驻，dashboard 对话
- **夜班 35B**（Qwen3.5-35B-A3B Q6_K，llama.cpp）：巩固 + 深度分析（thinking 保留）
- **任何时刻只有一个模型驻留**（48GB 机体装不下双驻留——2026-08-22 双 panic 教训）
- 夜班：挂 27B → 35B 巩固/图谱 → 停 35B → 起 27B 审校 → 恢复常驻

## 夜班流水线（night_pipeline.py）

```
segment1 门控+摄入（数据新鲜度检查 → L0 增量）
segment2 嵌入（L2 build：向量 + FTS5）
segment3 巩固（35B → L3 事实/优先级/提案）+ 知识图谱（27B 抽取）+ 深度审校（27B）
segment4 看门狗（L3 git 快照 → 过期提案 → 遗忘扫描）
产出：夜班报告（changelog + 今日应在意优先级清单）+ 修改提案（需用户批准）
```

## 模块清单（src/）

| 模块 | 职责 |
|---|---|
| `m4_ingest.py` / `l0_ingest.py` | L0 摄入（水位 md5 幂等） |
| `l2_semantic.py` | L2 语义索引（bge-m3 向量 + BM25，RRF 融合） |
| `knowledge_graph.py` | 实体/关系抽取（27B 无 thinking 输出干净 JSON） |
| `night_pipeline.py` | 夜班四段编排 + 门控 + 报告 + 看门狗 |
| `proposal_queue.py` | 修改提案（pending/approved/expired，睡眠代理不等人） |
| `m6_dashboard.py` / `m6_sidebar.py` | 本地 dashboard（报告/提案/对话/工具模式） |
| `vault.py` | 密钥系统（macOS Keychain，对话存/取密码 + 防泄漏打码） |
| `writeback.py` | L3 写回执行器（批准后应用） |
| `reminder_check.py` / `m8_urgent_watch.py` | 提醒规则（remind_after 到期才标高优先级） |
| `chat_capture.py` | 对话落 L0 |
| `vision_ingest.py` / `doc_ingest.py` | 图像/文档摄入 |
| `verify_night.py` | 夜班产物校验 |

## 目录结构

```
src/            核心代码（本仓库）
docs/           设计文档

models/         本地模型权重（40GB+，不在本仓库）
test-sandbox/   沙盒测试环境（隐私隔离，不在本仓库）
```

## 运行环境

- macOS（Apple Silicon），48GB 起
- Python venv：llama-cpp（夜班）、mlx-lm（白天）、doc-parse、l2 语义
- 模型：Qwen3.5-35B-A3B（夜班）/ Qwen3.8-27B-4bit（白天）/ bge-m3（嵌入）
- 所有模型服务仅监听 127.0.0.1
